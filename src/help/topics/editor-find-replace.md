## 本文を検索するには

エディタにフォーカスがある状態で {{command:find}} を押すと、検索バーが開く。
検索バーには「{{t:editor.find.caseSensitive}}」と「{{t:editor.find.regex}}」の切り替えと、「{{t:editor.find.prev}}」「{{t:editor.find.next}}」「{{t:editor.find.close}}」のボタンがある。

## 置換するには

{{command:findReplace}} で、置換の欄がある検索バーが開く。このコマンドは Windows と Linux だけで使える。
macOS を含め、エディタのツールバーの追加メニューにある「{{t:editor.toolbar.findReplace}}」からも、置換の欄がある検索バーを開ける。

## シーンの一覧を絞り込むには

{{panel:scenes}}パネルのツリーにフォーカスがある状態で {{command:find}} を押すと、シーンの絞り込み欄にフォーカスが移る。
