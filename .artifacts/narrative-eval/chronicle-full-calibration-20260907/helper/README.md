# Chronicle Luna max live helper\n\nThis directory contains the fixed, credential-free offline gate and the one-shot live runner for the approved diagnostic contract.\n\nRun ./run-offline.sh before any live execution. The live launcher reads one API key from its TTY, sends only the approved OpenRouter POSTs, and writes sanitized run metadata under the parent receipt directory.\n\nThe helper binds its source candidate, contract, fixture, runtime checkout, lockfiles, and command digest through manifest.json. Generated Vitest cache and scratch state belong outside this fixed inventory.\n
