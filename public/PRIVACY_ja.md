# Grimodex プライバシー通知

最終更新日: 2026-07-24
バージョン: v1.6

本通知は、Grimodex のデスクトップ版と Web Editor 試用版がデータをどこに保存し、ユーザーが AI を設定した場合に何を送信するかを説明します。利用規約と矛盾する場合は利用規約が優先します。

## 1. サービスの範囲

Web Editor はエディタ操作と Grimodex への引き継ぎを試すための試用版です。AI 付きサブスクリプションではなく、開発者が提供する AI 利用枠、共有 API キーまたはクラウド原稿解析は含みません。AI を使用する場合、ユーザー自身が管理する API キーまたは接続先を対応する HTTP プロバイダに明示的に設定します。ネイティブのサブプロセスを必要とする CLI プロバイダは Web Editor では利用できません。

## 2. 保存先

| サーフェス                                  | 主なデータ                                                                | 保存先                                     | 標準保持                                       |
| ------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------ | ---------------------------------------------- |
| Electron 版                                 | 本文、設定、チャット履歴、編集メタデータ                                  | ユーザー端末の SQLite                      | ユーザーが削除するまで                         |
| Web Editor 試用版                           | ワークスペース、本文、設定資料、チャット履歴、AI 応答                     | 現在のブラウザプロファイルの IndexedDB     | ワークスペースまたはサイトデータを削除するまで |
| Web Editor の UI・AI 設定（API キーを除く） | 表示設定、選択したプロバイダ・モデル、Ollama／OpenAI 互換エンドポイント等 | 現在のブラウザプロファイルの Local Storage | サイトデータを削除するまで                     |
| AI データ同意記録                           | ポリシーバージョン、経路、プロバイダ、実際の接続先、同意日時              | 現在のブラウザプロファイルの Local Storage | サイトデータを削除するまで                     |

Web Editor の IndexedDB はクラウド同期やバックアップではありません。サイトデータまたはブラウザプロファイルを削除すると復元できない場合があります。Web Editor は原稿を開発者のサーバーへアップロードまたは保存しません。

「Grimodex へ引き継ぐ」で生成される handoff ファイルはブラウザ内で作成され、ユーザーが指定したダウンロード先へ保存されます。ダウンロード後の保存、共有、削除およびバックアップはユーザーが管理します。

Web Editor の BYOK 用 API キーは現在のページの実行メモリにだけ保持します。IndexedDB、Local Storage または開発者のサーバーには保存せず、ページの再読み込みまたは終了後は再入力が必要です。

## 3. AI へ送信するデータ

Web Editor は、AI を自動的に有効化したり、ユーザーの操作なしに本文を AI へ送信したりしません。ユーザーが AI を設定し、送信直前の開示に同意してリクエストした場合に限り、次の一部または全部を選択した接続先へ送信します。

- ユーザーの指示、会話履歴およびシステム指示
- リクエストのために選択された本文、シーン、Codex、設定その他の文脈
- 選択したプロバイダが認証を必要とする場合、そのリクエストを認証するユーザー自身の API キー

送信される項目はリクエスト直前の開示画面に列挙します。ユーザーが同意しない場合、対象の AI リクエストは送信しません。

## 4. AI の処理先、保持およびモデル学習

### Ollama

リクエストはユーザーが設定した Ollama エンドポイントへ送信されます。通常のローカル構成ではユーザー端末またはユーザー管理のネットワーク内で処理されますが、リモートの Ollama エンドポイントを設定した場合はその運営者にもデータが送信されます。保存、保持、ログおよびモデル学習への利用は、ユーザーが選択したサーバー、モデルおよび運用設定に依存します。

- [Ollama Privacy Policy](https://ollama.com/privacy)

### OpenAI 互換エンドポイント

リクエストはユーザーが設定した実際の Base URL へ送信されます。API キーが必要な場合はページの実行メモリにだけ保持します。保存、保持、ログ、モデル学習、処理地域および CORS の対応状況は接続先の運営者とモデルに依存します。Grimodex は当該接続先へ送信する前に正規化した Base URL を表示し、接続先が変わった場合は再同意を求めます。

### OpenAI／Anthropic BYOK

リクエストは、ユーザー自身の API キーを使用して選択したプロバイダへ送信されます。Grimodex は AI の利用料金を負担せず、利用量、契約および課金はユーザーと各プロバイダの関係に基づきます。

プロバイダ側の保存、保持およびモデル学習への利用は、アカウント、契約、設定、モデルおよび各社の最新方針によって変わります。Grimodex が一律に保証するものではありません。送信前に表示される開示と次の方針を確認してください。

- [OpenAI API のデータ管理](https://platform.openai.com/docs/models/default-usage-policies-by-endpoint)
- [OpenAI のモデル改善におけるデータ利用](https://openai.com/policies/how-your-data-is-used-to-improve-model-performance/)
- [Anthropic のモデル学習方針](https://privacy.anthropic.com/en/articles/7996868-is-my-data-used-for-model-training)
- [Anthropic の保持期間](https://privacy.anthropic.com/en/articles/7996866-how-long-do-you-store-my-organization-s-data)

### OpenRouter BYOK

リクエストはユーザー自身の OpenRouter API キーで OpenRouter へ送信され、その後、選択したモデルとアカウントのルーティング設定に応じた下流の推論プロバイダが処理する場合があります。保存、保持およびモデル学習への利用は OpenRouter と下流プロバイダの設定・方針に依存します。

- [OpenRouter のデータ収集・プライバシー方針](https://openrouter.ai/docs/guides/privacy/data-collection)

### Sakana BYOK

リクエストはユーザー自身の Sakana API キーで Sakana AI API へ送信されます。利用可能なモデルや下流の処理先、保存、保持およびモデル学習への利用は、アカウント設定と同社の現行方針に依存します。Grimodex は原稿または API キーを受け取る本番中継サーバーを提供しません。

- [Sakana AI Privacy Policy](https://console.sakana.ai/privacy-policy)

### AI のべりすと BYOK

リクエストはユーザー自身の API キーで AI のべりすと（Bit192）の API へ送信されます。利用する legacy／v1 API とモデルによりリクエスト形式と機能が異なります。保存、保持およびモデル学習への利用は同サービスの現行方針に依存します。

- [AI のべりすと API 説明](https://ai-novel.com/account_api_help.php)
- [AI のべりすと利用規約](https://ai-novel.com/terms_of_use.html)

## 5. 明示的な同意

品質要件 `GDX-AI-CONSENT-001` に基づき、Grimodex は外部 AI または設定された Ollama エンドポイントへ送信する前に、次の情報を表示します。

1. 送信されるデータ
2. AI プロバイダ、処理目的および処理先
3. アプリ側と接続先側の保存先および保持期間
4. モデル学習への利用状況
5. 関連する利用・プライバシーポリシーへのリンク

同意はポリシーバージョン、経路、プロバイダおよび実際の接続先（Ollama／OpenAI 互換の場合は設定されたエンドポイント）の組合せに結び付けます。いずれかが変更された場合は再確認を求めます。未同意の場合、プロバイダ呼び出しの前に処理を中止します。

ブラウザが保存する同意記録には、原稿、プロンプト、AI 応答または API キーを含めません。AI リクエストの送信後は、選択した接続先の保持・削除方針が適用されます。

## 6. AI 以外の通信

Web Editor の静的ページを取得する際、ホスティング事業者は IP アドレス、時刻、User-Agent 等の標準的な接続情報を記録する場合があります。Web Editor はページ配信のために原稿本文を送信しません。

Electron 版は、ライセンス検証、更新確認、および意味検索モデルのダウンロードのために外部サービスへ接続する場合があります。これらの通信では著作物本文を送信しませんが、接続先に標準的な接続情報が記録される場合があります。

## 7. ユーザーの選択と削除

- AI 同意画面で拒否すると、その AI リクエストは送信されません。
- Web Editor のデータは、ワークスペースまたはブラウザのサイトデータを削除して消去できます。
- handoff ファイルは、ユーザーが保存した端末またはストレージから削除してください。
- ページを再読み込みまたは終了すると、Web Editor の実行メモリにある BYOK 用 API キーは失われます。
- 接続先へ送信済みのデータについては、各接続先の保持・削除方針を確認してください。
