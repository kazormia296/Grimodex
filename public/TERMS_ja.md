## 4. データの取り扱い

4.1. データの保存先は、利用するサーフェスによって異なります。

- **Electron 版:** 小説本文、設定資料、チャット履歴等は、原則としてユーザーの端末上の SQLite データベースに保存されます。ユーザーがリモート AI、ライセンス検証、更新確認等を明示的に利用しない限り、著作物データを外部へ送信しません。
- **Web Editor 試用版:** ワークスペース、本文、設定資料、チャット履歴および AI 応答は、利用中のブラウザプロファイルの IndexedDB に保存されます。UI・AI 設定（API キーを除く）は Local Storage に保存されます。クラウド同期またはバックアップではなく、サイトデータ、ブラウザプロファイルまたはワークスペースを削除すると失われる場合があります。Web Editor は原稿を開発者のサーバーへアップロードまたは保存しません。
- **handoff ファイル:** Web Editor から Grimodex へ引き継ぐためのファイルはブラウザ内で生成され、ユーザーが指定したダウンロード先へ保存されます。ダウンロード後の保管、共有、削除およびバックアップはユーザーが管理します。

  4.2. Web Editor で AI を使用するには、ユーザーが Ollama、OpenAI API または Anthropic API を明示的に設定する必要があります。開発者が提供する AI 利用枠はありません。BYOK 用 API キーは現在のページの実行メモリにだけ保持し、IndexedDB、Local Storage または開発者のサーバーへ保存しません。ページの再読み込みまたは終了後は再入力が必要です。

  4.3. AI へ送信する前に、本ソフトウェアは、少なくとも次の事項を経路ごとに表示し、ユーザーの明示的な確認を求めます: (a) 送信されるプロンプト、会話履歴、選択本文その他のデータ、(b) AI プロバイダ、処理目的および実際の接続先、(c) アプリと接続先側の保存先および保持期間、(d) モデル学習への利用状況、(e) 関連ポリシーへのリンク。同意は経路、プロバイダ、実際の接続先およびポリシーバージョンに結び付けられ、いずれかが変わった場合は再確認を求めます。同意しない場合、対象の AI 送信は行いません。

  4.4. AI リクエストには、ユーザーの指示、会話履歴、システム指示、および要求を実行するために選択された本文、シーン、Codex、設定等のコンテキストが含まれる場合があります。送信内容に第三者の個人情報、営業秘密その他の機密情報が含まれる場合、送信権限およびリスクを確認する責任はユーザーが負います。

  4.5. Ollama の処理先、保持および学習利用は、ユーザーが設定したエンドポイント、モデルおよび運用方針に依存します。OpenAI／Anthropic BYOK の保持および学習利用は、選択したプロバイダ、ユーザーの契約、アカウント設定およびモデルに依存し、Grimodex が一律に保証するものではありません。送信前の開示とリンク先の最新ポリシーを確認してください。

  4.6. AI データ同意の記録には、ポリシーバージョン、経路、プロバイダ、実際の接続先および同意日時だけをブラウザの Local Storage に保存する場合があります。この同意記録自体に原稿、プロンプト、AI 応答または API キーは含めません。

  4.7. 詳細は、同梱の [Grimodex プライバシー通知](./PRIVACY_ja.md) および送信直前に表示される各処理先のポリシーを参照してください。

  4.8. ユーザーは自身の責任でバックアップを行うものとします。本ソフトウェアの不具合、ストレージ障害、ブラウザのサイトデータ消去、誤操作等によるデータ損失に関する開発者の責任は、本規約第 6 条の定めに従います。

  4.9. 本ソフトウェアの有償版は、ライセンスの有効性を確認するため、決済・ライセンス管理事業者（Polar Software, Inc.）のサーバーと通信します。送信される情報は、ライセンスキー、アクティベーション識別子（ライセンス管理事業者が発行する端末ごとの匿名 ID）、および OS の種別を含むアクティベーションラベル（例:「Grimodex on Windows」）に限られ、ユーザーの著作物データや端末を一意に特定できる情報が含まれることはありません。通信はアクティベーション時および約 7 日ごとの再検証時に行われます。ネットワークに接続できない場合でも、最終確認から 30 日間は全機能を利用できます。

  4.10. ライセンスが無効・期限切れとなった場合でも、ユーザーが作成したデータの閲覧およびエクスポートは制限されません。

  4.11. 本ソフトウェアが外部のサーバーと通信する主な場合は次のとおりです。

- ユーザーが設定した第三者 AI サービスの利用時（第 2 条、4.3 から 4.5）

ユーザーが設定した AI への通信では、本条に記載した著作物データが送信される場合があります。ライセンス検証、更新確認およびモデルファイルのダウンロードでは、著作物データを送信しません。Web Editor の静的ページを取得する場合を含め、接続先のサーバー運営者に IP アドレス、時刻、User-Agent 等の接続情報が記録される場合があります。
