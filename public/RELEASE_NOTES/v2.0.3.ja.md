# v2.0.3

## 配布

- macOS 版の署名・公証処理を修正し、Developer ID で署名された配布物を安定して生成できるようにしました。
- Windows 版は方針どおり Authenticode 未署名で配布します。ビルド時の証明書自動検出を無効化し、成果物が意図せず署名されていないことをリリース前に検証します。

## 改善

- Windows の Electron テストを通常 CI に追加し、プラットフォーム固有の不整合をリリース前に検出できるようにしました。

## 修正

- macOS で `/var` と `/private/var` のような同一場所を指すパス表記が異なる場合でも、外部ファイルの権限と Codex のファイル変更承認を正しく扱えるようにしました。
- Windows のパス区切りや正規化の差異により、Codex、アップデーター、MCP サイドカーの検証が不安定になる問題を修正しました。
