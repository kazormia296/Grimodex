# v2.0.1

## 新機能

- Codex App Server との統合を追加し、コンテキストの遅延読み込み、入力補完、本文範囲と知識を結ぶ意味リンクに対応しました。
- Codex に登録した読みを本文のルビへ自動反映し、手動で付けたルビを Codex の読みとして保存できるようにしました。
- Zen モードに Paper / Glass のライブ背景と調整スタジオを追加し、執筆に集中できる表示を拡充しました。
- ブラウザ版 Editor をローカルファーストの試用環境として公開し、端末内の原稿読み込み、スマートフォン向け画面、ユーザー所有の AI とローカル HTTP / WebGPU 接続に対応しました。

## 改善

- 描画、起動、バックグラウンド索引作成を最適化し、長い作品でも編集を始めやすくしました。
- IME 変換中の著者帰属を安定させ、確定・取消・空データなどの入力境界をより正確に扱うようにしました。
- ワークスペースの Glass 表現とコントラスト設定、オンボーディング、ネイティブウィンドウのリサイズ動作を整えました。

## 修正

- AI の準備状態と Codex 入力補完、ルビやインライン要素を含む段落並べ替えの不具合を修正しました。
- セマンティック索引のメモリ割り当てによるクラッシュ、Editor 配備時の競合、Web Editor のチュートリアルと背景描画の問題を修正しました。
- Electron renderer の権限境界、外部ファイル読み込み、CLI 起動検証、依存パッケージの既知の脆弱性を強化・修正しました。
