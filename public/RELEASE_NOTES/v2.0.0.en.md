# v2.0.0

## New

- Migrated the desktop runtime to Electron and Chromium, with refreshed distribution paths for Windows, macOS on Apple Silicon, and Linux.
- The Rust search, AI, and database backend now runs locally through N-API, and the MCP server is bundled with the app.

## Improvements

- Existing Tauri installations can migrate while preserving workspaces, settings, and API keys.
- Removed WebKitGTK-specific workarounds that made vertical writing fragile and aligned editor behavior with Chromium.
- Strengthened update signing and integrity checks, plus AppImage, deb, rpm, and Arch Linux packaging.

## Fixes

- Prevented side-by-side installs during the Windows migration; failed validation now stops safely without changing user data.
- Arch Linux updates now stay under pacman or an AUR helper instead of invoking the in-app package updater.
