# 端末更新通達 // GRIMODEX REVISION v2.0.8

## 運用者《オペレーター》各位

大規模言語モデル統合型物語編纂端末《GRIMODEX》、Revision v2.0.8の更新記録です。

本改訂では、Glass効果の背景ぼかしと、厳格なContent Security Policy下でのスキャンデータ検証を修正しています。

## 解消済み異常

- Glass効果を有効にしても、Windowsデスクトップ版とWindows／Linux上のChrome Web Editorで背景ぼかしが反映されない不具合を修正しました。EditorとWorkspaceの両方で、本番ビルド後も標準の`backdrop-filter`が保持されます。
- ElectronおよびWeb Editorの厳格なContent Security Policyで、スキャンデータ検証が動的JavaScript生成として拒否される問題を修正しました。検証器をビルド時生成へ切り替え、Web Editorからデスクトップ版へのワークスペース読み込み機能を、ダイアログを開いたときだけ読み込むようにしました。

## システム改修

- Arch Linux向けAUR配布では、公開Release、配布アセットのSHA-256、AURのSSH host key、version順序を検証してから`grimodex-bin`を更新するようにしました。
