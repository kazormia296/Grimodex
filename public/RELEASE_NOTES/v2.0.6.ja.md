# v2.0.6

## 新機能

- デスクトップ基盤を Electron / Chromium へ移行し、Windows・macOS（Apple Silicon）・Linux 向けの配布経路を刷新しました。Rust 製の検索・AI・データベース機能と MCP サーバーもローカルで動作します。
- Codex App Server との統合、コンテキストの遅延読み込み、入力補完、本文と知識を結ぶ意味リンク、Codex の読みと本文ルビの相互反映に対応しました。
- Zen モードに Paper / Glass のライブ背景と調整スタジオを追加しました。
- ブラウザ版 Editor をローカルファーストの試用環境として公開し、端末内の原稿読み込み、モバイル表示、ユーザー所有の AI、ローカル HTTP / WebGPU 接続に対応しました。
- 日本語作品の Codex 名・別名・読みを、対応するローカル IME の変換辞書へ書き出せるようにしました。

## 改善

- 既存の Tauri 版から、ワークスペース・設定・API キーを保ったまま Electron 版へ移行できるようにしました。
- 描画、起動、バックグラウンド索引作成を最適化し、長い作品でも編集を始めやすくしました。
- IME 変換中の著者帰属、ワークスペースのコントラスト、オンボーディング、ネイティブウィンドウの操作を改善しました。
- macOS の Developer ID 署名・公証処理を安定化しました。Windows 版は方針どおり Authenticode 未署名で配布し、成果物が意図せず署名されていないことを CI で検証します。

## 修正

- Windows で旧 Tauri 版と Electron 版が重複インストールされる問題を防ぎ、移行検証に失敗した場合はユーザーデータを変更せず安全に停止するようにしました。
- macOS の `/var` と `/private/var` のような同一場所を指すパス表記や、Windows のパス区切り・正規化の差異を正しく扱うようにしました。
- セマンティック索引のメモリ割り当てによるクラッシュ、Codex 入力補完、ルビを含む段落並べ替え、Web Editor の配備・表示に関する問題を修正しました。
- 最終公開 Tauri v0.10.4 の実インストーラーを固定 SHA-256 で検証するよう移行 E2E を修正し、公開資産を認証なしで取得できるようにしました。
- Windows 移行 E2E で、Electron アンインストール後に登録が 0 件となる正常状態を PowerShell StrictMode が誤って失敗扱いする検証不具合を修正しました。
- Windows のリリースジョブでも `electron-updater` メタデータを正しいファイルパスで検証できるよう、シェルに依存する環境変数展開を修正しました。
