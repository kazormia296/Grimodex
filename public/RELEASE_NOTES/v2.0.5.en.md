# v2.0.5

## New

- Migrated the desktop runtime to Electron and Chromium with refreshed distribution paths for Windows, macOS on Apple Silicon, and Linux. The Rust search, AI, and database backend plus the MCP server now run locally.
- Added Codex App Server integration, lazy context loading, input completion, semantic links between manuscript text and project knowledge, and two-way synchronization between Codex readings and manuscript ruby.
- Expanded Zen mode with live Paper and Glass backgrounds plus an in-editor studio for tuning the ambience.
- Released the browser Editor as a local-first trial with on-device manuscript import, mobile-friendly views, user-owned AI, and local HTTP or WebGPU connections.
- Added local IME dictionary export for Codex names, aliases, and readings in Japanese projects.

## Improvements

- Existing Tauri installations can migrate to Electron while preserving workspaces, settings, and API keys.
- Optimized rendering, startup, and background indexing so large projects become ready for editing sooner.
- Improved authorship tracking during IME composition, workspace contrast, onboarding, and native window interactions.
- Stabilized Developer ID signing and notarization on macOS. Windows packages remain intentionally unsigned with Authenticode, and CI verifies that they were not signed unexpectedly.

## Fixes

- Prevented side-by-side Tauri and Electron installations on Windows; failed migration validation now stops safely without changing user data.
- Correctly handle equivalent macOS paths such as `/var` and `/private/var`, along with Windows path separator and normalization differences.
- Fixed semantic-index memory allocation crashes, Codex input completion, paragraph reordering around ruby, and Web Editor deployment and rendering issues.
- Corrected the migration E2E to verify the actual final public Tauri v0.10.4 installer with a pinned SHA-256 and download the public asset without credentials.
- Fixed the Windows migration E2E verifier so PowerShell StrictMode accepts the expected zero uninstall registrations after removing Electron.
