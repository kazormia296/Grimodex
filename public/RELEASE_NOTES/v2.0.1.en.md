# v2.0.1

## New

- Added Codex App Server integration with lazy context loading, input completion, and semantic links between manuscript spans and project knowledge.
- Codex readings can now be applied to manuscript ruby automatically, while manually added ruby can be saved back as a Codex reading.
- Expanded Zen mode with live Paper and Glass backgrounds plus an in-editor studio for tuning the ambience.
- Released the browser Editor as a local-first trial with on-device manuscript import, a focused mobile workspace, user-owned AI, and local HTTP or WebGPU connections.

## Improvements

- Optimized rendering, startup, and background indexing so large projects become ready for editing sooner.
- Made authorship tracking more reliable across IME composition, commit, cancellation, and empty-data edge cases.
- Refined workspace Glass and contrast controls, onboarding, and native window resizing.

## Fixes

- Fixed AI readiness and Codex input completion, along with paragraph reordering around ruby and expanded inline elements.
- Fixed semantic-index memory allocation crashes, Editor deployment races, and Web Editor tutorial and background-rendering issues.
- Hardened Electron renderer permissions, external file reads, CLI launch validation, and dependencies with known vulnerabilities.
