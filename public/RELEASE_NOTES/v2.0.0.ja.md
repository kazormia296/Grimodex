# v2.0.0

## 新機能

- デスクトップ基盤を Electron / Chromium へ移行し、Windows・macOS（Apple Silicon）・Linux 向けの配布経路を刷新しました。
- Rust 製の検索・AI・データベース機能を N-API 経由でローカル実行し、MCP サーバーもアプリに同梱しました。

## 改善

- 既存の Tauri 版から、ワークスペース・設定・API キーを保ったまま移行できるようにしました。
- 縦書きを不安定にしていた WebKitGTK 固有の回避処理を撤去し、Chromium に合わせた一貫した編集動作へ整理しました。
- 自動更新の署名・整合性検証と、Linux の AppImage / deb / rpm / Arch 向けパッケージ経路を強化しました。

## 修正

- Windows で旧版と新版が重複インストールされる問題を防ぎ、移行に失敗した場合はユーザーデータを変更せず安全に停止するようにしました。
- Arch Linux ではアプリ内更新を無効化し、pacman / AUR 経由の更新に統一しました。
