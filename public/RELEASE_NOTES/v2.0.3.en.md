# v2.0.3

## Distribution

- Fixed the macOS signing and notarization path so Developer ID-signed packages can be produced reliably.
- The Windows build remains intentionally unsigned with Authenticode. Certificate auto-discovery is disabled, and release CI verifies that the artifacts were not signed unexpectedly.

## Improvements

- Added the Electron test suite to the regular Windows CI job so platform-specific inconsistencies are detected before release.

## Fixes

- Fixed external-file permissions and Codex file-change approvals on macOS when equivalent paths use aliases such as `/var` and `/private/var`.
- Fixed Windows path separator and normalization differences that could make Codex, updater, and MCP sidecar validation unreliable.
