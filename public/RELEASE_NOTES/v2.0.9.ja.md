# 端末更新通達 // GRIMODEX REVISION v2.0.9

## 運用者《オペレーター》各位

大規模言語モデル統合型物語編纂端末《GRIMODEX》、Revision v2.0.9の更新記録です。

本改訂では、複数ペインや外部更新が重なる場面の文書保存、Inline AI、Beat操作を保護し、AI接続、Chronicle、Glass、Web Editor、Vivliostyle出力を改善しています。日本語／英語のデスクトップ版には、関連シーン候補を端末内で再順位付けする実験的機能も追加しています。

## ⚠️ インストール前に必ずお読みください

### プラットフォーム別配備区分

- **Windows / Linux**: v2.0.8 と同じく、正式版（Stable）の配備区分を継続します。
- **macOS**: v2.0.8 と同じく、Apple Silicon 向けのオープンベータを継続します。macOS 固有の動作および配布経路には、未確認の不具合が残存する可能性があります。重要な原稿で使用する前にバックアップを作成し、複製したデータまたは試し書きで動作を確認してください。

### v2.0.8 からの更新と v0.10.4 からの移行

- 本 Release の公開後、v2.0.8 の対応パッケージではアプリ内更新を利用できます。更新が提示されない場合は、v2.0.9 の Assets から対象環境の配布物を手動で取得してください。
- Arch Linux はアプリ内更新を使用しません。AUR の `grimodex-bin` が v2.0.9 へ更新された後、pacman または AUR helper で更新してください。
- v0.10.4 は自動更新機能を備えていません。本 Release の公開後、v2.0.9 の Assets から対象環境の配布物を手動で取得してください。本 Release の workflow では、Windows 版インストーラーを公開済み v0.10.4 の実インストーラーから移行する E2E で検証します。旧版の登録状態を検証できない場合は、旧版およびユーザーデータを変更せずに処理を停止します。
- ワークスペースおよび設定には既存のローカルデータ領域を引き続き使用します。初回起動時に、API キーを OS の資格情報ストアから Electron の暗号化ストレージへ移行する処理を試みます。安全な OS ストレージを利用できない場合、または移行に失敗した場合は警告を表示するため、設定画面で API キーを再入力してください。旧資格情報は削除しません。
- 大切な原稿は、更新前にご自身でもバックアップしてください。

### コード署名およびセキュリティ警告

- **Windows**: v2.0.9 のインストーラーは Authenticode 未署名です。Windows がセキュリティ警告を表示することがあります。インストーラーは必ず公式配布ページから取得し、出所を確認してください。
- **macOS**: Apple Silicon 向けです。本 Release の workflow で Developer ID 署名と Apple 公証を検証した v2.0.9 のアプリおよび DMG を提供します。
- **Linux**: v2.0.9 では AppImage、deb、rpm、Arch package を x86_64 向けに用意します。

### データ保管および AI 利用

- 原稿とプロジェクトデータは、端末内の SQLite データベースへ保存されます。Grimodex の利用にアカウントは必須ではありません。
- AIチャットは、OpenRouter / OpenAI / Anthropic の API キー、Ollama のローカルモデル、または Claude Code / Codex CLI / OpenCode などのエージェント型 CLI で利用できます。Ollama と各 CLI は別途導入し、必要な設定、認証、起動を完了してください。AI を設定しなくてもエディタは使用できます。
- デスクトップ版に埋め込みモデルがない場合、プロジェクトを開いたときの自動索引作成で、言語に応じた約 34〜37 MB のモデルを取得するためネットワーク接続が発生することがあります。モデルの取得中または利用できない場合も、全文検索は利用できます。
- 実験的な Semantic reranking の再順位付け自体は、デスクトップ版に同梱したローカルモデルで実行します。選択された関連シーンの抜粋は、通常のAIチャットと同じく、設定したAI providerへ送信する文脈に含まれる場合があります。

## 新規機能

- 日本語／英語プロジェクトのデスクトップ版に、関連シーン候補をローカルモデルで再順位付けする実験的な Semantic reranking を追加しました。プロジェクト設定で明示的に有効化した場合だけ動作し、関連シーンの自動注入が前提です。Web Editorおよびその他の言語では利用できません。処理が遅い場合、競合した場合、または失敗した場合は、従来の検索順をそのまま使用します。

## 改善

- 文書保存、外部更新、ワークスペース切替、複数ペインで、本文と保存世代を同じ基準で管理するようにしました。保存失敗や競合を切替処理まで伝播し、未保存のローカル編集へ別ペインの本文を重ねないようにしています。
- OllamaとOpenAI互換ローカルendpointを含むAI provider／model一覧を復旧しました。Ollamaではモデルの最大contextと実行中runnerの実効contextを分け、Agent toolや出力予約を含む送信全体の使用量をContext表示と送信前検証へ反映します。
- Chronicleの一括日付／レーン操作、Undo／Redo、Workspace切替中の対象Project、時刻表示を強化しました。side dockは領域を閉じて再表示したとき、以前のスロットと表示状態を安全に復元します。
- AutoSave後のLint、revision、派生情報、意味索引処理をバックグラウンド処理へ分離し、長文保存中の操作応答と性能計測を安定させました。
- Vivliostyle出力は生成完了後に保存ダイアログを自動表示し、文庫判／新書判の柱にある作品タイトルを横書きで保持します。
- Web Editorのstripe、dock、チャット、選択ツールバーの寸法とアイコンを整理し、試用案内を閉じられるようにしました。設定画面のnavigationと更新進捗表示も画面内へ収まるように調整しています。
- Glassとライブ背景では、メニュー表示やpanel開閉時のぼかしを維持し、角丸周辺の屈折とアンチエイリアスを改善しました。

## 解消済み異常

- Inline AIのプレビュー／取消処理、A/B候補の採用、Beatのdrag & dropが、開始時と異なるeditor session、本文、表示対象、またはBeat配列へ適用される可能性を修正しました。
- 別ペインで保存した本文と保存世代が分離し、その後の保存で不要な競合や古い状態が残る問題を修正しました。旧形式のBeat preview補完も同じ保存世代へ含めています。
- AutoSave失敗、外部import、退役したeditor sessionが競合したとき、古い本文revisionやBeatなどの付随データが最新状態として公開される可能性を修正しました。
- layout presetまたはsplit layoutの切替後にScene treeが空になる問題と、Codexの表示filterが本文highlightや候補検索へ漏れる問題を修正しました。
