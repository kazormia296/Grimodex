# GRIMODEX // TERMINAL REVISION v2.0.8

## OPERATOR NOTICE

This is the revision record for v2.0.8 of the GRIMODEX LLM-integrated narrative authoring terminal.

This revision restores Glass background blur and corrects scan data validation under a strict Content Security Policy.

## RESOLVED ANOMALIES

- Fixed an issue where enabling Glass left the background unblurred in Windows desktop builds and the Chrome Web Editor on Windows or Linux. Both the Editor and Workspace now retain the standard `backdrop-filter` declaration in production builds.
- Fixed scan data validation being rejected as runtime JavaScript generation by the strict Content Security Policy in Electron and the Web Editor. The validator is now generated at build time, and the Web Editor workspace handoff importer loads only when opened.

## SYSTEM MODIFICATIONS

- AUR publishing for Arch Linux now validates the public Release, distribution asset SHA-256, AUR SSH host key, and version ordering before updating `grimodex-bin`.
