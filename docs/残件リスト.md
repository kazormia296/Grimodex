# 残件リスト（設計書 vs 実装 比較）

最終更新: 2026-04-03

---

## 1. Chat パネル

**未実装・不足:**
- Extended Thinking（拡張思考）パラメータの UI と API 連携
- Tool Use（Function Calling）によるエージェント機能 → AIエージェント設計書参照
- コンテキストクリエイター（AI が必要なコンテキストを自動提案する「✦ AI」ボタン）
- Context budget allocation（レイヤー別トークン予算配分の管理・可視化）
- Model compatibility の可視化（Tool Use 対応状況の UI 表示）

---

## 2. Codex パネル

**未実装・不足:**
- `children_budget`（サブツリートークン予算）: 親エントリ注入時に子孫エントリを自動注入する機能
- サブツリートークン予算プリセット（none/compact/standard/generous）
- タグの色管理（色付きタグ表示）
- エントリのアイコン画像管理（BLOB カラムはスキーマにあるが UI 未実装）
- リレーション提案の自動検出と Dismiss 機能
- 「Pin with children」機能（サブツリー含めてピン留め）

---

## 3. Snippets パネル

**未実装・不足:**
- グリッドレイアウト（パネル幅に応じた 1〜3 カラム切り替え）
- Snippet から「Open in Editor」（Editor タブで内容を直接編集）
- `usage_count` の自動更新（挿入するたびにインクリメント）
- クリップボードからスニペット作成（Ctrl+V）
- D&D 挿入後のハイライトアニメーション（パープル背景 → 2 秒フェード）
- Snippet content での Authorship Mark 付与

---

## 4. Attribution パネル

**未実装・不足:**
- Scope セレクター（Project / Part / Chapter / Scene 単位の切り替え）
- チャプターグルーピング（折りたたみ可能な行）
- モデル使用状況セクション（生成モデル別集計）
- Attribution レポートのエクスポート（Markdown / CSV）
- フィルタモード（特定ソースのテキストを強調表示）
- Scope の自動追従（Editor のアクティブシーン変更時）

---

## 5. Scenes パネル

**未実装・不足:**
- Synopsis（シーン要約）の表示・編集
  - インライン表示、ツールチップ表示
  - 「✦ Generate」AI 生成ボタン
  - ステータス遷移時の自動生成提案
- Outline ビューモード（Synopsis 全文をインライン展開表示）
- AI 帰属バッジのピル表示（`[34%]`）
- storySoFar カバレッジ警告（未記入 Synopsis の割合ピル）
- ステータス別フィルタ・タイトル検索
- Word count / Status によるソート

---

## 6. Editor パネル

**未実装・不足:**
- Synopsis / Summary セクション（ヘッダー折りたたみエリア + AI 生成ボタン）
- Breadcrumb のインタラクション（クリックでシーン切り替え等）
- Inline AI パレット（`/` コマンド、Ctrl+Shift+Space）
  - Replace / Continue / Expand 等の複数コマンド
- Ruby annotation（日本語小説向け傍注）
- Editor Focus モード（現在シーン以外を暗くする）
- Typewriter モード（カーソル行を常に中央固定）の完全実装

---

## 7. Settings パネル（最優先）

現在は `AiSettingsDialog` のみ実装。フル Settings パネルが未実装。

**未実装カテゴリ:**
- **Project**: Title、Genre、POV、Tense、Language、Style guide、AI instructions
- **AI**: Context budget allocation（レイヤー別予算管理）、コスト表示
- **Editor**: Font、Line height、Typewriter mode、Spell check、Smart quotes、Inline AI 設定
- **Display**: Theme、Accent color、UI language、UI scale、Attribution highlight opacity
- **Keys**: キーバインドカスタマイズ
- **Data**: バックアップ、エクスポート、DB コンパクション、チャット履歴削除

---

## 8. AI エージェント（Tool Use）

設計書に定義されているが完全未実装。

**未実装:**
- エージェントモードトグル（Chat パネルヘッダーの 🔧 アイコン）
- ツール定義
  - `search_codex`、`list_codex_by_type`、`get_codex_entry`、`list_codex_tags`
  - `search_scenes`、`get_scene`、`search_snippets`
  - `get_chapter_summaries`
- ツール呼び出しの可視化（フォールディング可能なブロック表示）
- ツール呼び出し上限（1 メッセージあたり 10 回）
- トークン予算（ツール結果用に 30% 割り当て）

## 11. リビジョン履歴

インフラ（DB・API）は整っているが UI が未完。

**未実装・不足:**
- 差分表示（Diff）機能（追加/削除の色付けハイライト、「Show changes」トグル）
- プロジェクトスナップショット UI（一覧モーダル、作成・復元）
- 自動リビジョン間隔の設定 UI（デフォルト 5 分）
- リビジョン保持上限の設定 UI（デフォルト 50 件）

## 優先度サマリー

| 優先度 | 項目 | 理由 |
|--------|------|------|
| 高 | Settings パネル（フル実装） | 現状 AI 設定のみで機能が大幅不足 |
| 高 | Scenes パネル Synopsis 機能 | storySoFar 注入・企画機能の中核 |
| 高 | AI エージェント（Tool Use） | Chat パネルの差別化機能 |
| 中 | Inline AI パレット | Editor の生産性向上 |
| 中 | Revision History UI（完全版） | インフラ済み、UI のみ |
| 中 | Attribution パネル Scope セレクター | 分析機能の実用性向上 |
| 低 | Snippets グリッドレイアウト等 | UX 改善 |
| 低 | レイアウトカスタマイズ永続化 | UI の洗練 |
