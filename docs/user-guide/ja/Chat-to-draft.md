# Chatから本文へ

> 対象バージョン: Grimodex 2.0.10
>
> 対象: Electron版 / Web Editor
>
> 最終動作確認: 2026-08-02

このページでは、現在のシーンについてChatで相談し、役立つ情報をCodexやSnippetへ整理し、必要なものだけ本文へ反映する流れを説明します。

## 1. 相談対象を固定する

1. Scenesで対象シーンを開きます。
2. Chatを開き、シーン名と相談内容が正しいことを確認します。
3. 必要なら選択範囲、Codex、他シーン、作品設定をコンテキストへ追加します。

シーンごとに会話履歴が分かれるため、シーンを切り替えた後は、意図した履歴と本文が表示されているか確認してください。

## 2. 依頼を小さくする

最初から作品全体を送るのではなく、目的と対象を明示します。

- 「このシーンの会話の論点を3つ挙げる」
- 「この設定に矛盾する箇所があるか、本文の範囲だけで確認する」
- 「次の場面の候補を複数案出す」

回答を本文へ採用する前に、事実、作品設定、語り口、ネタバレ範囲を確認します。

## 3. CodexとSnippetを使い分ける

| 保存先 | 向いている内容 |
| --- | --- |
| Codex | キャラクター、場所、用語、世界観、設定、関係性 |
| Snippet | そのまま再利用したい文章、アイデア、短い候補 |
| 本文 | 採用を決めた完成原稿 |

チャットの回答をそのまま本文へ貼るのではなく、再利用する知識はCodexやSnippetへ一度整理すると、後のシーンで参照しやすくなります。

## 4. 抽出内容を確認する

ChatのメッセージからCodexまたはSnippetを作成するときは、タイトル、種別、本文、関連付けを確認して保存します。自動抽出した内容は、作品の正本として確定する前に人が確認してください。

AIの出力には誤り、推測、既存設定との矛盾が含まれることがあります。Codexへ保存したことは、内容が正しいことを意味しません。

## 5. 本文へ反映する

1. CodexまたはSnippetを開き、採用する部分だけを選びます。
2. 現在のシーンと挿入位置を確認します。
3. 本文へ挿入します。
4. 文脈、文体、重複、出所表示を確認してから編集を続けます。

AI由来の挿入部分にはaiの出所情報が付く場合があります。手で修正しても出所表示が維持されることがあるため、Attributionで確認してください。

## AIエージェントを使う場合

Electron版では、Claude Code、Codex CLI、OpenCodeなどのCLIエージェントを接続できます。CLIエージェントは通常のHTTP Chatとは経路と権限が異なります。

- CLIのログイン状態と契約は端末側で管理します。
- CLIエージェントはWeb Editorでは使えません。
- 単発の構造化AI機能など、CLI経路に対応しない機能はHTTPプロバイダーを求める場合があります。
- MCP連携で書き込み権限を与える場合は、信頼できるローカルクライアントだけに限定してください。

## AIを使わずに同じ作業をする

Chatを使わず、本文、Note、Codex、Snippetを手動で作成しても構成管理はできます。AIをオフにしても、保存、整理、校閲、エクスポートは利用できます。

## 保存されるデータ

Chat履歴、Codex、Snippet、本文はデスクトップ版ではワークスペースのSQLiteに保存されます。Web EditorではブラウザのIndexedDBに保存されます。

## 外部へ送信されるデータ

Chatや抽出、インラインAI、校閲を実行した場合、入力、会話履歴、選択した本文・Codex・設定などが選択したAI接続先へ送られることがあります。送信前の開示と接続先を確認してください。

## よくある問題

### Chatの文脈が広すぎる

選択範囲、Codex、他シーン、作品設定を減らします。AI設定のコンテキスト設定で除外できる項目も確認してください。

### 抽出したCodexが期待と違う

抽出対象を短くし、種別と保存先を明示して再実行します。既存のCodexを上書きする前に、内容を比較してください。

### CLIでは一部のAI機能が動かない

機能別モデル設定でHTTPプロバイダーを指定する必要がある場合があります。CLIの実行状態と、機能が必要とする構造化出力やツール対応も確認してください。
