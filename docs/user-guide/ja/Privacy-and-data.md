# データとプライバシー

> 対象バージョン: Grimodex 2.0.10
>
> 対象: Electron版 / Web Editor
>
> 最終動作確認: 2026-08-02

このページは、初回設定や通常操作で判断しやすいように、保存場所と外部通信を要約したものです。法的な定義、例外、プロバイダーごとの保持条件は、必ず[プライバシー通知（日本語）](../../../public/PRIVACY_ja.md)を確認してください。

## どこに保存されるか

| データ | Electron版 | Web Editor |
| --- | --- | --- |
| 本文、Codex、Snippet、Chat履歴、作品設定 | ワークスペースのSQLite | ブラウザのIndexedDB |
| 自動バックアップ | ワークスペースのbackupsフォルダー | アプリの自動DBバックアップなし |
| UIや同意などの設定 | アプリの設定領域 | ブラウザのLocal Storage等 |
| APIキー | 設定したデスクトップの資格情報・設定経路 | 実行中ページのメモリのみ |

Web EditorのIndexedDBは、クラウド同期や開発者によるバックアップではありません。ブラウザデータを失う前にエクスポートしてください。

## 原稿本文が外部へ送られる条件

原稿本文、選択範囲、シーン、Codex、作品設定、会話履歴などが外部AIへ送信されるのは、概ね次の条件が揃ったときです。

1. 接続先やプロバイダーを設定している。
2. AI処理の送信前に、送信内容と接続先の開示を確認している。
3. Chat、抽出、インライン生成、校閲などをユーザーが実行している。

必要なコンテキストだけが送られる場合もありますが、機能によっては他シーン、Codex、設定資料、履歴が含まれます。送信前の開示を最終確認としてください。

## AI接続先と保持

- OpenAI、Anthropic、OpenRouterなどのクラウドAIは、各社のAPI契約、アカウント設定、下流ルーティング先の方針に従います。
- Ollamaは設定したOllamaサーバーとモデルの運用方針に従います。
- OpenAI互換エンドポイントは、そのURLの運用者と下流サービスの方針に従います。
- Sakana、AIのべりすとなどの外部プロバイダーは、各サービスの利用条件に従います。
- CLIエージェントは、端末上のCLIとそのサービスのログイン・保持方針に従います。

Grimodexが接続先の保存期間や学習利用を保証するものではありません。APIキーも、送信先が必要とする場合は認証ヘッダー等で接続先へ渡ります。

## AI以外の通信

Electron版では、AIを実行していなくても次の通信が発生する場合があります。

- ライセンス検証
- 更新確認
- 意味検索用モデルのダウンロード

意味検索モデルの取得は、プロジェクトを開いたときの索引作成で発生する場合があります。v2.0.10のリリースノートでは、モデルサイズの目安を約34〜37 MBとしています。取得できない場合も全文検索は利用できます。

これらの通信で原稿本文を送ることを意味しません。通信の目的を分けて考えてください。

## Web検索

Web検索を有効にすると、検索クエリが第三者の検索プロバイダーへ送信される場合があります。公開Web検索のターンにはプロジェクトのコンテキストや会話履歴を含めず、本文を扱うプライベートAgentターンではWeb検索を無効化する設計です。

検索結果のページには、AIへの指示に見せかけた悪意ある文章が含まれる可能性があります。結果を確認し、取得ページの指示をそのまま実行しないでください。

## 外部クライアントとMCP

MCPサーバーやCLIエージェントへ書き込み権限を与える場合、クライアントは本文やプロジェクト情報を読み取り、設定に応じて変更できます。読み取り専用、作品単位、全作品のどのスコープを選んだかを確認し、信頼できるローカルクライアントだけに接続してください。

## 保存されるデータ

デスクトップ版の詳細な保存場所と復旧方法は[保存・バックアップ・入出力](Data-backup-and-transfer.md)を参照してください。Web Editorは、長期保存の前にエクスポートを作成してください。

## よくある問題

### AIへ送る本文を減らしたい

選択範囲を狭め、Codex、他シーン、会話履歴、RAGのコンテキストを必要なものだけにします。送信前の開示で実際の宛先と内容を確認します。

### APIキーをIssueに貼ってしまいそう

貼らないでください。キーを削除・ローテーションし、接続先の管理画面で利用状況を確認します。原稿、grimodex.db、ログも、機密情報を除かずに共有しないでください。
