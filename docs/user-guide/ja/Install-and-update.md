# インストールと更新

> 対象バージョン: Grimodex 2.0.10
>
> 対象: Electron版
>
> 最終動作確認: 2026-08-02

## 使う配布物を選ぶ

最新の公開状態、チェックサム、Assetsの実在は、必ず[GitHub Releases](https://github.com/kazormia296/GrimodexReleases/releases)で確認してください。v2.0.10の配布形式は次の構成です。

| 環境 | 公開区分 | 手動導入用形式 |
| --- | --- | --- |
| Windows x64 | Stable | .exe |
| macOS Apple Silicon | Open Beta | .dmg |
| Linux x86_64 | Stable | .AppImage / .deb / .rpm |
| Arch Linux x86_64 | Stable | .pkg.tar.zst、またはAURのgrimodex-bin |

ブラウザで試す場合は[Web Editor](https://grimodex-try.pages.dev/)を使います。Web EditorとElectron版の保存先は別です。

## 事前に確認すること

- Linux向け配布物はglibc 2.39以上が必要です。deb版はlibstdc++6 12以上も必要です。
- macOS版はApple Silicon向けのOpen Betaです。重要な原稿を開く前に複製したワークスペースで確認してください。
- Windows版インストーラーはv2.0.10時点でAuthenticode未署名です。OSの警告が表示される場合があります。公式Releaseから取得したファイルだけを使い、配布元を確認してください。
- macOS版はRelease workflowでDeveloper ID署名と公証を検証した配布物です。警告が出た場合も、取得元とファイルの整合性を確認してください。
- Arch Linux版は環境に応じてXWayland経路を使います。XWaylandを利用できる環境で使用してください。

## インストール手順

1. 公式ReleaseからOSとCPUに合う配布物を取得します。
2. OSの案内に従ってインストールします。
3. Grimodexを起動し、ランチャーで既存ワークスペースを開くか、新しいワークスペースを作成します。
4. 既存のワークスペースを開く前に、重要なデータのコピーを作成しておきます。
5. [10分クイックスタート](Quickstart-10-minutes.md)で、シーンを作成して保存できることを確認します。

見覚えのないワークスペースや外部ファイルを開くときは、信頼できる出所か確認してください。

## v2.0.9から更新する

- 公開後のv2.0.9対応デスクトップ版では、アプリ内更新が提示される場合があります。
- 更新が提示されない場合は、公式Releaseからv2.0.10の配布物を手動で取得します。
- Arch Linuxはアプリ内更新ではなく、AURのgrimodex-binを更新します。AUR側がv2.0.10になったことを確認してから更新してください。
- 更新前にワークスペースをバックアップしてください。更新が原稿データをクラウドへコピーすることはありません。

APIキーの保存方式を含む設定移行が必要な場合があります。設定画面に再入力の案内が出たときは、接続先を確認してからAPIキーを入力してください。

## 古いv0.10.4から移行する

v0.10.4には自動更新がないため、v2.0.10の公式Releaseから対象環境の配布物を手動で取得します。更新前に、ワークスペース全体を別の場所へコピーし、コピーした方で初回起動と作品の表示を確認してください。

## 保存されるデータ

インストーラーの更新とワークスペースの保存は別です。原稿は選択したワークスペース内に保存されるため、アプリをアンインストールする前にワークスペースを退避してください。

## 外部へ送信されるデータ

インストール自体は原稿本文を開発者サーバーへ送信しません。Electron版では、ライセンス検証、更新確認、意味検索モデルの取得などの通信が発生する場合があります。AI処理を実行した場合の送信内容は[データとプライバシー](Privacy-and-data.md)を参照してください。

## よくある問題

### OSがインストーラーを警告する

取得元が公式Releaseか、OSとCPUが一致しているかを確認します。Windows版の未署名警告はv2.0.10の既知の配布条件です。出所やファイルの整合性を確認できない場合はインストールを中止してください。

### Linuxで起動しない

glibc、deb版のlibstdc++6、CPUアーキテクチャを確認します。Wayland環境ではXWaylandの有無も確認してください。

### Web Editorでデスクトップの作品が見えない

自動同期はありません。デスクトップからエクスポートまたはハンドオフ用ファイルを書き出し、Web Editor側で手動インポートしてください。
