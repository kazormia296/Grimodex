# AI接続ガイド

> 対象バージョン: Grimodex 2.0.10
>
> 対象: Electron版 / Web Editor
>
> 最終動作確認: 2026-08-02

## まず接続方式を選ぶ

AIは必須ではありません。接続先を選ぶときは、料金、データの送信先、保持期間、ローカルで完結するか、Web Editorでも使うかを先に決めます。

| 接続方式 | 必要なもの | 主な処理先 | Electron版 | Web Editor |
| --- | --- | --- | --- | --- |
| OpenRouter | APIキー、モデル | OpenRouterと選択された下流プロバイダー | 対応 | 対応 |
| OpenAI | APIキー、モデル | OpenAI | 対応 | 対応 |
| Anthropic | APIキー、モデル | Anthropic | 対応 | 対応 |
| OpenAI互換 | Base URL、必要ならAPIキー、モデル | 設定したサーバー | 対応 | 接続先のCORS等に依存 |
| Ollama | 起動中のOllama、モデル | 設定したOllamaサーバー | 対応 | 接続先の公開設定・CORS等に依存 |
| Sakana / AIのべりすと | 各サービスの認証情報、モデル | 各サービス | 対応 | 対応範囲は画面と接続先に依存 |
| CLIエージェント | Claude Code、Codex CLI、OpenCodeの導入・認証 | ローカルCLIと各サービス | 対応 | 非対応 |
| AI無効 | なし | 外部AI処理なし | 対応 | 対応 |

OpenAI互換方式は、llama.cpp、LM Studio、vLLM、自前ホストなど、互換APIを提供するサーバーにも使えます。実際に使えるAPI経路、モデル名、認証、CORSはサーバー側の設定に依存します。

## ChatGPTやClaudeの契約との違い

ChatGPTやClaudeのWebアプリのサブスクリプションと、API利用の契約は同じとは限りません。GrimodexのAPI接続には、選択したサービスのAPIキーと、そのサービスで有効な請求・利用条件が必要です。

CLIエージェント方式では、GrimodexがAPIキーを管理するのではなく、端末に導入済みのCLIとそのログイン状態を使います。CLIの契約、権限、データ保持は各サービスに従います。

## 設定手順

1. 設定からAIを開きます。
2. プロバイダーを選びます。
3. APIキー、エンドポイント、モデルを入力します。OpenAI互換の場合はBase URLを確認します。
4. モデル一覧を更新します。取得できないときは、接続先に存在するモデルIDを手入力できる場合があります。
5. Chatの既定モデルと、必要なら機能別モデルを選びます。
6. 送信前に、実際の接続先、送信データ、保存・保持・学習利用の説明を確認します。
7. 同意してテスト用の短い依頼を送り、応答を確認します。

APIキーや本文を含むテストは、信頼できる接続先に対してのみ行ってください。

## AIへ送られるもの

AI処理を実行すると、依頼内容に応じて次の情報が送信対象になります。

- 入力した指示、システム指示、会話履歴
- 選択した本文、シーン、Codex、Snippet、プロジェクト設定
- AI機能が必要とする検索・構成・校閲用のコンテキスト
- 接続先が必要とするAPIキーなどの認証情報

常にプロジェクト全体が送られるとは限りませんが、機能によっては他シーンや設定資料がコンテキストに含まれます。送信前の開示に表示された接続先と内容を確認してください。

## 接続先を変えたとき

接続先やエンドポイントが変わると、同じ入力でもデータの処理者、保持期間、学習利用の条件が変わります。再同意を求められた場合は、変更後の宛先を確認してから同意してください。

## Web Editorの制限

Web EditorではCLIエージェントは利用できません。OpenAI互換サーバーやOllamaへブラウザから接続する場合、サーバーをブラウザから到達可能にし、CORSや認証を正しく設定する必要があります。ローカルサーバーを不用意にインターネットへ公開しないでください。

Web検索を有効にした場合、検索クエリは第三者の検索プロバイダーへ送信される場合があります。公開Web検索のターンにはプロジェクトのコンテキストを含めない設計ですが、取得ページにはプロンプトインジェクションが含まれる可能性があるため、結果を確認してから利用してください。

## 保存されるデータ

デスクトップ版のAI設定はアプリの設定領域に保存されます。Web EditorのBYOKキーは実行中のページメモリにだけ保持され、再読み込みまたは終了時に消去されます。接続先側のログや履歴は、Grimodexの保存とは別に管理されます。

## 外部へ送信されるデータ

AI処理を実行した場合、送信先は設定したプロバイダーまたはCLIが利用するサービスです。Grimodexの開発者サーバーがAIの中継先になるとは限りません。接続先の保持・学習・安全ログのポリシーを確認してください。

## よくある問題

### モデル一覧を取得できない

APIキー、Base URL、モデル一覧APIの対応状況、ネットワークを確認します。接続先が一覧APIを提供しない場合は、正しいモデルIDを手入力します。

### APIキーが拒否される

キーの有効期限、請求設定、選択したプロバイダー、エンドポイント、モデル名を確認します。Webアプリの契約だけではAPI利用できない場合があります。

### Ollamaへ接続できない

Ollamaが起動しているか、設定したエンドポイントから到達できるか、対象モデルがインストール済みかを確認します。Web Editorでは、ブラウザから到達できる公開設定とCORSも確認します。

### CLIが見つからない

Claude Code、Codex CLI、OpenCodeが端末のPATHから実行でき、認証済みであることを確認します。CLIエージェントはElectron版のみです。
