# トラブルシューティング / FAQ

> 対象バージョン: Grimodex 2.0.10
>
> 対象: Electron版 / Web Editor
>
> 最終動作確認: 2026-08-02

## まず確認すること

1. Electron版かWeb Editorかを確認します。
2. Grimodexのバージョン、OS、CPUアーキテクチャを控えます。
3. 重要な原稿なら、操作を続ける前にワークスペースをコピーします。
4. AIを使っている場合は、プロバイダー、モデル、エンドポイント、発生時刻を控えます。
5. 原稿、APIキー、データベース全体、資格情報を公開ログやIssueへ貼らないでください。

## 起動しない・インストールできない

### Windows

v2.0.10のWindowsインストーラーはAuthenticode未署名です。警告が出た場合は、公式Releaseから取得したファイルか、OSとCPUが対応しているかを確認します。出所を確認できないファイルは実行しないでください。

### macOS

Apple Silicon向けのOpen Betaです。対応CPU、公式Releaseの配布物、Developer ID署名・公証の状態を確認します。重要な原稿は複製したワークスペースで試します。

### Linux

glibc 2.39以上、deb版の場合はlibstdc++6 12以上が必要です。Wayland環境ではXWaylandの有無も確認します。Arch Linux版はXWayland経路を使うため、環境側で利用できることを確認してください。

## ワークスペースが開けない

- 選んだフォルダーがワークスペースのルートか確認します。
- ルートにgrimodex.dbがあるか確認します。
- .grimodex/workspace.jsonを削除せずに残します。
- 読み取り権限、ディスク容量、他のプロセスによるロックを確認します。
- 直前にファイルを同期・移動した場合は、まずワークスペースのコピーを作り、コピー側で試します。

DBを直接編集したり、別のSQLiteツールで修復したりする前に、元ファイルを退避してください。

## 本文が表示されない・最新ではない

現在のワークスペース、作品、シーンが正しいか確認します。保留中の保存が完了するまで待ち、必要ならシーンを再度開きます。外部Markdownシーンでは、ファイル側の変更競合を確認し、ローカル保持か再読み込みを選びます。

## モデル一覧が空

- プロバイダー、APIキー、Base URL、ネットワークを確認します。
- 接続先がモデル一覧APIを提供しているか確認します。
- 正しいモデルIDを手入力できる場合は、接続先のドキュメントと照合します。
- Ollamaではサーバーが起動し、選択したモデルがインストール済みか確認します。
- Web Editorからローカル接続する場合は、CORSとブラウザからの到達性を確認します。

## APIキーが拒否される

APIキーの有効期限、請求状態、対象プロバイダー、モデル権限、エンドポイントの組み合わせを確認します。ChatGPTやClaudeのWebアプリ契約が、API利用権限を自動で意味するとは限りません。キーを画面やログへ表示した状態で共有しないでください。

## AI応答が遅い・コンテキスト超過になる

選択範囲、他シーン、Codex、会話履歴、検索結果を減らします。モデルのコンテキスト窓と最大出力、Ollamaの実効コンテキストも確認します。回答予約分を含めて上限を超える場合があります。

## CLIエージェントが動かない

Claude Code、Codex CLI、OpenCodeが端末から実行できるか、ログインが有効か、権限があるかを確認します。CLIエージェントはElectron版のみです。単発の構造化AI機能などはCLIに対応せず、HTTPプロバイダーが必要な場合があります。

## Web EditorからローカルAIへ接続できない

ブラウザから接続先へ到達できるか、サーバーがLANやlocalhostで適切に待ち受けているか、CORS、認証、HTTPS混在制限を確認します。ローカルAIサーバーを認証なしでインターネットへ公開しないでください。

## 意味検索モデルを取得できない

ネットワーク、空き容量、プロキシ、ファイアウォールを確認します。取得できない間も全文検索を使える場合があります。モデル取得が繰り返し失敗する場合は、バージョンとログの概要を控えて報告します。

## バックアップから戻したい

[保存・バックアップ・入出力](Data-backup-and-transfer.md)を読み、復元前に現在のワークスペース全体をコピーします。設定のDataからバックアップを選び、日時と対象を確認して二段階の確認を行います。復元はワークスペース全体を置き換え、完了後にアプリを再読み込みします。

## エクスポートの表示が想定と違う

ルビ、傍点、縦書き、改行、サイトプリセット、対象シーンの選択を確認します。エクスポートはプレビューや生成結果を確認してから、投稿先へ渡してください。SQLiteの完全バックアップが必要な場合は、エクスポートではなくワークスペースバックアップを使います。

## IMEの挙動がおかしい

OS、デスクトップ版のバージョン、IME、WaylandまたはXWayland、再現する入力欄と確定操作を控えます。特定バージョンの既知修正は[最新リリースノート](../../../public/RELEASE_NOTES/v2.0.10.ja.md)で確認してください。原稿や辞書の内容をそのまま公開ログへ出さないでください。

## 不具合を報告する

次の情報を、機密情報を除いて報告します。

- Grimodexのバージョン
- Electron版またはWeb Editor
- OS、CPU、Wayland/XWaylandなどの実行環境
- AIを使う場合のプロバイダーとモデル名（APIキーは除く）
- 再現手順と期待した結果
- 実際に起きた結果
- 再現頻度と、直前に行った変更

公開Issueには、原稿本文、grimodex.db、APIキー、アクセストークン、未加工のログを添付しないでください。脆弱性や秘密情報の露出は、公開IssueではなくリポジトリのSecurity機能で非公開に報告してください。
