# Grimodexとは

> 対象バージョン: Grimodex 2.0.10
>
> 対象: Electron版 / Web Editor
>
> 最終動作確認: 2026-08-02

## この製品でできること

Grimodexは、日本語小説の本文を書くためのエディタに、次の作業をまとめたアプリです。

- シーン単位のリッチテキスト編集
- 作品の章立て、フォルダー、メモの整理
- キャラクターや世界観などのCodex管理
- シーンごとに分かれたAIチャット
- ChatからCodexやSnippetを作る情報整理
- Grid、Beat、Map、Timeline、Matrixなどを使った構成管理
- 校閲、リンター、用語、関連シーンの確認
- 出所情報を付けた本文挿入と、複数形式へのエクスポート

## AIは任意です

AI接続を設定しなくても、ワークスペースを作成して本文を書く、構成を整理する、校閲する、エクスポートするという基本作業は利用できます。

AIを使う場合は、自分で選んだクラウドAPI、OpenAI互換エンドポイント、ローカルサーバー、またはデスクトップ版のCLIエージェントを接続します。GrimodexがAIモデルやクラウドアカウントを自動で用意するわけではありません。

## ローカルファーストの意味

デスクトップ版では、ワークスペース内のSQLiteデータベースが原稿・作品データの中心です。通常の執筆内容を開発者のサーバーへ同期する機能はありません。

ただし、「ローカルファースト」は「一切通信しない」という意味ではありません。

- ユーザーが実行したAI処理では、選択した本文やコンテキストが設定した接続先へ送られます。
- Electron版では、ライセンス検証、更新確認、意味検索モデルの取得などで通信する場合があります。
- Web Editorでは、ブラウザと接続先の通信に加え、ブラウザの標準的な接続情報が発生します。

詳しくは[データとプライバシー](Privacy-and-data.md)と公式の[プライバシー通知](../../../public/PRIVACY_ja.md)を確認してください。

## デスクトップ版とWeb Editorの違い

| 項目 | Electron版 | Web Editor |
| --- | --- | --- |
| 保存場所 | 選択したワークスペースのSQLite | 現在のブラウザプロファイルのIndexedDB |
| CLIエージェント | Claude Code、Codex CLI、OpenCodeに対応 | 非対応 |
| ローカルファイル | ワークスペース、バックアップ、外部Markdownを扱える | ブラウザのファイル操作と手動ハンドオフが中心 |
| 自動同期 | なし。ファイルまたはエクスポートで移動 | なし。手動でデスクトップへ引き継ぐ |
| AIなしの執筆 | 対応 | 対応 |

Web Editorのデータはクラウドバックアップではありません。ブラウザのデータ削除、プロファイル変更、サイトデータの消去に備えて、必要な作品はエクスポートしてください。

## 現行ランタイムについて

現行のデスクトップ版はElectronをサポート対象としています。古いTauri版に関する内部移行コードは、現行版の導入方法やサポート対象を示すものではありません。インストールは[公式Release](https://github.com/kazormia296/Grimodex/releases)の配布物を使ってください。

## 保存されるデータ

デスクトップ版では、本文、Codex、Snippet、チャット履歴、作品設定などがワークスペースのSQLiteデータベースに保存されます。ワークスペースの構造とバックアップの扱いは、[ワークスペースと作品構造](Workspace-and-project-structure.md)と[保存・バックアップ・入出力](Data-backup-and-transfer.md)を参照してください。

## 制限

- AIの応答品質、料金、保持期間は接続先に依存します。
- Web Editorはデスクトップ版のファイル操作やCLI連携をすべて持ちません。
- AIから挿入した文章には出所情報が付く場合があります。これは生成内容の正しさや権利関係を保証するものではありません。
