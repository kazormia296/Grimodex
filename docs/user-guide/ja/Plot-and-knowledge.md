# プロットと設定管理

> 対象バージョン: Grimodex 2.0.10
>
> 対象: Electron版 / Web Editor
>
> 最終動作確認: 2026-08-02

本文を書く前に、設定、出来事、因果関係、伏線を整理したいときに使うページです。名称や配置はUIの更新で変わる場合がありますが、作業目的ごとに機能を選ぶと迷いにくくなります。

## 作業目的と機能

| やりたいこと | 主に使う機能 |
| --- | --- |
| キャラクター、場所、用語を管理する | Codex |
| Chatから設定知識を抽出する | Chat、Codex |
| 文章やアイデアを再利用する | Snippet |
| 章やシーンの流れを考える | Grid、Beat |
| シーンの関係や分岐を図で見る | Map、Matrix |
| 作中時間や出来事を並べる | Timeline |
| 物語の段階や公開順を整理する | Phase |
| 伏線の仕込みと回収を追う | Foreshadow |

## Codexを正本として使う

1. Codexにキャラクター、場所、用語、世界観などのエントリを作ります。
2. 名前、別名、読み、関係、説明を入力します。
3. 関連するシーンや設定を確認します。
4. Chatや校閲で参照させる場合は、AIコンテキスト設定と公開範囲を確認します。

Codexは本文の代わりではなく、本文を支える知識ベースです。作品設定が変わったらCodexと本文の両方を確認してください。

## GridとBeatで構成する

- Gridでは章・シーンの並びと概要を俯瞰します。
- Beatでは一つのシーンや場面に必要な出来事、狙い、転換を分解します。
- Beatから本文を生成する場合は、生成前にプロバイダー、送信コンテキスト、出力を確認します。

構成案は本文へ確定する前の作業データです。AIが提案したBeatやあらすじを採用する場合は、既存設定との整合性を確認します。

## Map、Matrix、Timelineを使う

- Mapはアイデア、関係、分岐を視覚的に整理します。
- Matrixは複数の観点やシーン間の対応を比較します。
- Timelineは作中時間、出来事、配置を確認します。

各画面で表示される対象範囲や並び順は、作品の設定と現在のシーン選択に依存します。表示されないときは、対象シーンに作中時間や関係が設定されているかを確認してください。

## PhaseとForeshadowを使う

Phaseは、シーンを読む順序、作中時間、情報が明かされる段階など、作品のフェーズを整理するために使います。ミステリーや叙述トリックでは、後の設定を早いシーンのAIコンテキストへ漏らさない設定が重要です。

Foreshadowは、伏線のsetup、回収候補、強度、配置を追跡します。自動提案は候補であり、伏線が実際に成立しているかは本文と物語全体を確認してください。

## Chatと組み合わせる

1. Codexや構成案を先に作ります。
2. Chatで、対象シーンと目的を限定して相談します。
3. 有用な設定をCodex、再利用文をSnippetへ抽出します。
4. 採用した結果を本文へ反映し、必要ならMap、Timeline、Foreshadowを更新します。

プロジェクト全体を毎回送るのではなく、必要なコンテキストだけを選ぶと、情報漏えいと不要なコストを抑えられます。

## 保存されるデータ

Codex、Snippet、構成、関係、伏線、作品設定は、デスクトップ版ではワークスペースのSQLiteに保存されます。

## 外部へ送信されるデータ

画面を開いたり手動で整理したりするだけでは、原稿をAIへ送信しません。AIによる抽出、提案、分析を実行すると、選択した本文・設定・履歴が接続先へ送信される場合があります。

## 制限

- MapやTimelineなどの表示は、必要な関係・日時・アンカーが設定されている部分だけを対象にします。
- AIの提案は作品の正本ではありません。
- Web Editorはデスクトップ版と同じファイル・CLI連携を持ちません。
