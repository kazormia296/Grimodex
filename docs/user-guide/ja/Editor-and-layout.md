# Editorとレイアウト

> 対象バージョン: Grimodex 2.0.10
>
> 対象: Electron版 / Web Editor
>
> 最終動作確認: 2026-08-02

## このページで分かること

本文を書くときは、Scenesで作品構造を確認し、Editorで現在のシーンを編集します。Chat、Codex、校閲などは必要なときだけ表示し、レイアウトプリセットで作業目的に合わせて切り替えます。

## 基本操作

1. Scenesから編集したいシーンを選びます。
2. Editorで本文を入力・編集します。
3. シーンを切り替える前に、現在の編集内容が保存済みであることを確認します。
4. 文章の一部をAIへ送る場合は、送信する選択範囲とコンテキストを確認します。

シーンごとに独立したエディタとChat履歴を持つため、複数のシーンを並行して扱うときは、現在選択されているシーンを意識してください。

## レイアウトプリセット

現行UIには、作業目的に応じた次のプリセットがあります。

| プリセット | 向いている作業 |
| --- | --- |
| Write | 本文を広く表示して執筆する |
| Plan | 章立てや構成を確認する |
| Chat | Chatと本文を行き来して相談する |
| Proofread | 校閲やリンターの結果を見ながら直す |
| Condense | 情報量の多い画面を整理して表示する |

プリセットは固定されたパネル数を意味しません。目的に合うプリセットを選んだ後、必要なパネルだけを表示してください。

## 本文の出所を確認する

Grimodexは、本文へ挿入されたテキストにhuman、ai、unknownの出所情報を記録できます。

- human: ユーザーが入力した本文
- ai: AIチャットなどから挿入された本文
- unknown: 外部ペースト、インポート、古いデータなど出所を確定できない本文

出所情報は、内容の正しさ、著作権、利用許諾を自動判定するものではありません。公開・投稿前には本文を自分で確認してください。

## ChatやScene Contextを使う

現在のシーンについてAIに相談するときは、Chatを使います。関連する本文、Codex、設定、過去シーンなどをコンテキストとして追加できる機能があります。

コンテキストが多いほど回答が適切になるとは限りません。送信対象が広がるほど、接続先へ渡る情報とトークン量も増えます。AI送信前の開示を読んで、必要な範囲だけを選択してください。

## レイアウトを自分で調整する

- 本文に集中するときはWriteを選び、Chatや補助パネルを閉じます。
- 構成を確認するときはPlanを選び、Grid、Beat、Map、Timelineなどを開きます。
- Chatから本文へ反映するときはChatを選び、現在のシーンと挿入先を確認します。
- 校閲時はProofreadを選び、指摘と本文を同時に確認します。

パネルを閉じてもデータは削除されません。必要なパネルはメニューやレイアウト設定から再表示できます。

## 保存されるデータ

通常のシーン本文はワークスペースのSQLiteに保存されます。自動保存の間隔などは設定できます。外部Markdownシーンは、保存時に指定したMarkdownファイルへも書き戻されます。

## 外部へ送信されるデータ

本文入力やレイアウト変更だけで本文をAIへ送信することはありません。Chat、インラインAI、校閲などのAI機能を実行したときは、機能と選択したコンテキストに応じて本文・設定・履歴が送信されます。

## よくある問題

### 書いた内容が表示されない

現在のシーンが正しいか、別のワークスペースを開いていないかを確認します。保存処理の完了を待ち、必要ならシーンを再度開きます。

### AIへ送りたくない設定が含まれる

送信前のデータ開示とコンテキスト設定を確認します。Codexや他シーンをAIから除外する設定を使い、必要な範囲だけを選択してください。

### 外部Markdownの書式が違う

外部Markdownシーンは通常のSQLiteシーンと異なる制限付きの書式です。ルビ、出所Markなどが必要な本文は、通常のシーンで管理してください。
