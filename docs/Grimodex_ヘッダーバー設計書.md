# Grimodex ヘッダーバー設計書

## 概要

アプリウィンドウ最上部に固定表示されるバー。OSネイティブのタイトルバーとは別に、アプリコンテンツ領域の一番上に配置されるカスタムヘッダー。

---

## 構造

```
┌─────────────────────────────────────────────────────────────────────┐
│  OS ネイティブタイトルバー（ウィンドウ操作ボタン）                     │  ← OS管理
├─────────────────────────────────────────────────────────────────────┤
│  [ワークスペース▾]  Grimodex  ──────  [レイアウト▼] [パネル▼] [↓] [⚙] │  ← アプリヘッダー
├─────────────────────────────────────────────────────────────────────┤
│                       ドックゾーン領域                               │
```

### 各要素の配置

| 位置 | 要素 | コンポーネント |
|------|------|-------------|
| 左端 | ワークスペースメニュー | `WorkspaceMenu` |
| 左から2番目 | アプリ名 "Grimodex" | `<h1>` 固定テキスト |
| 中央（スペーサー） | `flex-1` の空白 | — |
| 右から4番目 | レイアウトプリセット | `LayoutPresetDropdown` |
| 右から3番目 | パネルトグル | `PanelToggleDropdown` |
| 右から2番目 | エクスポート | `<button>` + `Download` アイコン |
| 右端 | 設定 | `<button>` + 歯車アイコン |

---

## OSネイティブタイトルバーとの関係

Tauriのウィンドウはデフォルト設定（`decorations: true`）を使用しており、OSネイティブのタイトルバー（最小化・最大化・閉じるボタン）はOS側で管理する。アプリのカスタムヘッダーはそのネイティブタイトルバーの**下**に表示されるReactコンポーネントである。

- OSタイトルバーのドラッグ移動・ウィンドウリサイズはOS標準の挙動に委ねる
- アプリヘッダーにウィンドウドラッグ用のCSS（`-webkit-app-region: drag` 等）は設定しない

## ワークスペースメニュー（左端）

### 表示

```
[プロジェクト名▾]
```

- ボタンにアクティブなワークスペース名（フォルダ名）を表示
- 名前が長い場合は最大幅40文字で省略（truncate）
- ワークスペース未選択時は「ワークスペース」と表示

### ドロップダウン展開時

```
┌──────────────────────────────────┐
│ ✓ プロジェクト名（現在）           │  ← アクティブ表示
├──────────────────────────────────┤
│   最近のプロジェクト1             │  ← 最大4件
│   最近のプロジェクト2             │
│   最近のプロジェクト3             │
├──────────────────────────────────┤
│   他のフォルダを開く…             │
│   新規ワークスペース              │
├──────────────────────────────────┤
│   スタート画面                   │
├──────────────────────────────────┤
│   プロジェクトスナップショット…    │
│   整合性チェック                  │
└──────────────────────────────────┘
```

### 各メニュー項目の動作

| 項目 | 動作 |
|------|------|
| アクティブ表示（✓） | 操作なし、現在のワークスペースを視覚的に示す |
| 最近のプロジェクト | クリックで該当パスのワークスペースに切り替え |
| 他のフォルダを開く… | OSのフォルダ選択ダイアログを開き、選択パスのワークスペースを開く |
| 新規ワークスペース | OSのフォルダ選択ダイアログを開き、選択パスに新規ワークスペースを作成 |
| スタート画面 | スタート/ランチャー画面を表示 |
| プロジェクトスナップショット… | スナップショット作成ダイアログを開く |

### 動作仕様

- クリックで展開/折りたたみ切り替え
- click-outside でドロップダウンを閉じる
- メニュー項目をクリックすると自動的にドロップダウンが閉じる

## アプリ名（"Grimodex"）

- `<h1>` タグで表示する固定テキスト
- クリック動作なし（ロゴ・ブランディング表示のみ）
- フォント: `text-xl font-bold`

## エクスポートボタン（右から2番目）

- `Download` アイコン（lucide-react）
- クリックでエクスポートダイアログを開閉
- ツールチップ: `エクスポート (Ctrl+Shift+E)`
- キーボードショートカット: `Ctrl+Shift+E`
- 詳細は[エクスポートダイアログ設計書](Grimodex_エクスポートダイアログ設計書.md)を参照

---

## 設定ボタン（右端）

- 歯車アイコン（`Settings` from lucide-react）
- クリックで設定ダイアログを「project」カテゴリで開く
- ツールチップ: `設定 (Ctrl+Alt+,)`
- キーボードショートカット: `Ctrl+Alt+,`

---

## レイアウトとスタイル

```
height:     auto（py-2 相当、縦方向は内容に合わせる）
padding:    px-4 py-2
border:     下辺に border-b border-border
flex:       items-center gap-3（要素間に均一なギャップ）
shrink:     flex-shrink-0（ドックゾーンの高さに押しつぶされない）
```

## 将来の検討事項

- **Tauriフレームレス化**: `decorations: false` にしてアプリヘッダーをOSタイトルバーとして兼用する場合、ヘッダーに `-webkit-app-region: drag` を設定し、ボタン類に `-webkit-app-region: no-drag` を設定する必要がある
- **プロジェクトタイトルの表示**: アプリ名「Grimodex」の代わりに（または隣に）現在開いているプロジェクト名をヘッダー中央に表示する案
- **最近のプロジェクト上限**: 現在4件固定。設定で変更可能にするか検討
