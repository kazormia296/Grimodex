# Grimodex ヘッダーバー設計書

## 概要

アプリウィンドウ最上部に固定表示されるバー。`decorations: false`（フレームレスウィンドウ）設定により、OSネイティブのタイトルバーを非表示にし、アプリヘッダーがウィンドウドラッグやウィンドウ操作ボタンの役割も兼ねる。

---

## 構造

```
┌────────────────────────────────────────────────────────────────────────────────────┐
│ [Logo] [ワークスペース▾] [↶][↷] [↓ エクスポート]  ──  [レイアウト▼] [パネル▼] [⚙ 設定] │ [─][□][×] │
└────────────────────────────────────────────────────────────────────────────────────┘
```

### 各要素の配置

| 位置 | 要素 | コンポーネント |
|------|------|-------------|
| 左端 | アプリロゴ | `GrimodexLogo` |
| 左から2番目 | ワークスペースメニュー | `WorkspaceMenu` |
| 左から3番目 | Undo / Redo | `HistoryButtons`（`Undo2` / `Redo2` アイコン） |
| 左から4番目 | エクスポート | `<button>` + `FileOutput` アイコン + ラベル |
| 中央（スペーサー） | `flex-1` の空白 | — |
| 右から4番目 | レイアウトプリセット | `LayoutPresetDropdown` |
| 右から3番目 | パネルトグル | `PanelToggleDropdown` |
| 右から2番目 | 設定 | `<button>` + `Settings` アイコン + ラベル |
| 仕切り線 | 縦の区切り線（非mac環境のみ） | `<div>` |
| 右端 | ウィンドウ操作ボタン（非mac環境のみ） | `WindowControls` |

**現状の実装**: macOS では OS ネイティブのトラフィックライトを表示するため、`WindowControls` と仕切り線は非表示となり、ヘッダー左側に `pl-20` のパディングを設けてトラフィックライト分のスペースを確保している（`data-platform-mac` 属性で切り替え）。

---

## フレームレスウィンドウ設定

Tauriのウィンドウは `decorations: false` で設定しており、OSネイティブのタイトルバーを非表示にしている。

- ヘッダー全体に `data-tauri-drag-region` を設定し、ウィンドウのドラッグ移動を可能にする
- ボタン類はクリックイベントが優先されるため、ドラッグ操作の対象外となる
- ウィンドウの最小化・最大化・閉じるボタンは `WindowControls` コンポーネントで提供する

---

## アプリロゴ（左端）

- `GrimodexLogo` SVGコンポーネント
- `height={24}` で固定表示
- `currentColor` を使用しテーマに追従（`text-foreground`）
- クリック動作なし

---

## Undo / Redo ボタン（左から3番目）

`HistoryButtons` コンポーネント。`globalHistoryStore` が公開する `past` / `future` スタックを参照する。

- アイコン: `Undo2` / `Redo2`（lucide-react）
- ツールチップ: 直近操作のラベルがあれば `元に戻す: <label> (Ctrl+Z)` / `やり直し: <label> (Ctrl+Shift+Z)` の形式
- スタックが空のときは `disabled` 状態（`opacity-30`、ポインタ無効化）
- 失敗時は sonner トーストで通知（`history.undoError` / `history.redoError`）

---

## ワークスペースメニュー（左から2番目）

### 表示

```
[プロジェクト名▾]
```

- ボタンにアクティブなワークスペース名（フォルダ名）を表示
- 名前が長い場合は `max-w-40`（10rem）で省略（truncate）
- ワークスペース未選択時は `workspaceMenu.fallback`（「ワークスペース」）を表示

### ドロップダウン展開時

```
┌──────────────────────────────────┐
│ ✓ プロジェクト名（現在）           │  ← アクティブ表示
├──────────────────────────────────┤
│   最近のプロジェクト1             │  ← 最大4件
│   最近のプロジェクト2             │
│   最近のプロジェクト3             │
├──────────────────────────────────┤
│   他のフォルダを開く…             │
│   新規ワークスペース              │
├──────────────────────────────────┤
│   スタート画面                   │
├──────────────────────────────────┤
│   Novelcrafterからインポート…     │
│   プロジェクトスナップショット…    │
└──────────────────────────────────┘
```

### 各メニュー項目の動作

| 項目 | 動作 |
|------|------|
| アクティブ表示（✓） | 操作なし、現在のワークスペースを視覚的に示す |
| 最近のプロジェクト | クリックで該当パスのワークスペースに切り替え |
| 他のフォルダを開く… | OSのフォルダ選択ダイアログを開き、選択パスのワークスペースを開く |
| 新規ワークスペース | OSのフォルダ選択ダイアログを開き、選択パスに新規ワークスペースを作成 |
| スタート画面 | スタート/ランチャー画面を表示 |
| Novelcrafterからインポート… | Novelcrafter エクスポート ZIP の取り込みダイアログを開く |
| プロジェクトスナップショット… | スナップショット作成ダイアログを開く |

**現状の実装**: 「他のフォルダを開く…」と「新規ワークスペース」はどちらも同じ `handleOpenOther` ハンドラ（OS のフォルダ選択ダイアログ → `requestOpenWorkspace`）にバインドされている。新規作成専用フローは未実装。

### 動作仕様

- クリックで展開/折りたたみ切り替え
- click-outside でドロップダウンを閉じる
- メニュー項目をクリックすると自動的にドロップダウンが閉じる

## 設定ボタン（右から2番目）

- 歯車アイコン（`Settings` from lucide-react）＋ `app.settingsLabel`（「設定」）テキストラベル
- クリックで設定ダイアログを「project」カテゴリで開く
- ツールチップ: `設定 (Ctrl+Alt+,)`
- キーボードショートカット: `Ctrl+Alt+,`
- `open-settings` カスタムイベント（`detail.category`）でも開閉可能（他コンポーネントから任意カテゴリを指定できる）

---

## ウィンドウ操作ボタン（右端）

`WindowControls` コンポーネント。設定ボタンとの間に縦の区切り線（`h-4 w-px bg-border`）を配置。

| ボタン | アイコン | ツールチップ | 動作 |
|--------|---------|-------------|------|
| 最小化 | `Minus` | 最小化 | ウィンドウを最小化 |
| 最大化/復元 | `Square` / `Copy` | 最大化 / 元に戻す | 最大化状態をトグル |
| 閉じる | `X` | 閉じる | ウィンドウを閉じる |

- 閉じるボタンはホバー時に赤色背景（`hover:bg-red-600`）
- Tauri環境以外では非表示
- macOS では OS ネイティブのトラフィックライトを使うため、`WindowControls` と仕切り線そのものを描画しない

## レイアウトとスタイル

```
height:     auto（py-1 相当、縦方向は内容に合わせる）
padding:    px-4 py-1（macOS のみ pl-20 でトラフィックライト分を確保）
border:     下辺に border-b border-border
flex:       items-center gap-3（要素間に均一なギャップ）
shrink:     flex-shrink-0（ドックゾーンの高さに押しつぶされない）
drag:       data-tauri-drag-region（ヘッダー全体がウィンドウドラッグ領域）
glass:      glass-shell クラスで背景ぼかし/グラスエフェクトを継承
```

**現状の実装**: スクリーンショット撮影モード中はヘッダーに `no-screenshot` クラスが付与され、キャプチャ対象から除外される。
