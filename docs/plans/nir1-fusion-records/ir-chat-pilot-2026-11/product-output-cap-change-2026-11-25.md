# 製品の chat の出力上限の変更と、chat の IR pilot への影響（2026-11-25）

凍結済みの事前登録（`preregistration-v3.2.md`）と結果（`results/`）は改訂しない。この文書は、凍結の後に製品の値が変わったことの記録。

## 変わったこと

- 事前登録は「`max_tokens` は 4,096（thinking を含む）＝製品の chat と同じ値」と固定している（2.1、決定 8）。これは凍結の時点（2026-11-07、origin/master a2309b95）の製品の値。
- 2026-11-25 の修正で、製品は Anthropic の 5 系（Fable／Mythos の全版、Opus／Sonnet／Haiku の 5 以降）と、adaptive thinking を送る 4.6〜4.8 に 32,000 を送る。chat、agent、要約が同じ値を使う。文脈の応答の予約も同じ値になる。pilot の answer の model（Sonnet 5.5、Haiku 5.5）は 5 系に入る。
- 理由：agent で、adaptive thinking が 4,096 を使い切り、text も tool 呼び出しも無い `stop_reason: max_tokens` が実 API で再現した（5 本中 5 本）。

## pilot への影響

- **取った結果はそのまま使える。** 本測定の前の通しでは、4,096 に達した request は 0／72（出力の最大 2,087）。事前登録 6.4 の切れの数え方と停止の規則は、当時の値に対するもの。
- **「製品と同じ」は、この変更より後には成り立たない。** 正式な試験を行う場合は、次を取り直して新しい事前登録に書く（2026-11-08 の決定で、正式な試験は当面行わない）。
  - `max_tokens` の製品の値
  - 費用の最悪値（事前登録 6 節の「全件 4,096」の列は、32,000 では大きく増える。出力は実際の token で課金されるので、中央の見込みは上限だけでは変わらない）
  - 文脈の応答の予約が増えることによる、入力に入る量の違い
