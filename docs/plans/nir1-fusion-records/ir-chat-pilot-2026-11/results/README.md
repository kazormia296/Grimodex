## 正式な試験の規模の見積り（1.3）【推測】

方法と前提は `sizing.json`（`scripts/sizing.mjs`）。観測した不一致率と cluster の相関を入れた計算で、**正式な試験が pilot と同じ設計・同じ judge であること**を仮定する。両側 α 0.05、検出力 0.8。

- 入力：B−A の質問ごとの差の平均 +13.6 pt、質問ごとの差の SD 33.6 pt。項目の A・B の対応は、両方再現 25・A だけ 4・B だけ 26・どちらも不再現 118（173 項目）で**不一致率 17.3％**、ほぼ B だけの片方向。cell（作品×地点）の相関は ICC 0.0826（cell 間の分散 0.00954、質問の分散 0.10592。cell 4 件からの積率法）。
- **cluster を無視した下限**：差 10 pt を検出するのに 89 問（項目の不一致率からは 52 問相当）、5 pt に 356 問（210）、3 pt に 988 問（585）。
- **cell を cluster にした場合**（作品数 = cell 数 ÷ 2、各作品 2 地点が独立という楽観的な前提）：10 pt に cell 11〜14（作品 6〜7、cell あたり 80〜20 問、計 280〜880 問）。5 pt に cell 37〜49（作品 19〜25、計 980〜2960 問）。3 pt には cell 97〜132。cell 間の分散が 2 倍なら 10 pt に cell 20、5 pt に 71（cell あたり 40 問）。cluster の分散が 0 なら 10 pt に cell 5、5 pt に 11。
- **質問を増やしても残る下限**：cluster の分散だけで、cell 4 なら ±0.2032、8 なら ±0.1126、16 なら ±0.0732、32 なら ±0.05。pilot の 4 cell×約 17 問の検出できる最小の差は約 25 pt。**要点は質問数より作品・地点数**。
- **作品を cluster にした入れ子**（作品 2 件の差からの 1 自由度の見積りで、信頼できない）：10 pt に作品 14〜16（各 2 地点）、5 pt には作品 50〜56。作品間の差（g-ja-1 と m-ja-2）が大きいため、作品数が支配的。
- **pilot の区間の読み方**：上の区間は cell を固定した層別 bootstrap。4 cell の平均として t 区間を取ると +13.4 pt [−6.7, +33.4]（df 3）と 0 を含む。「差あり」とも「差なし」とも言えず、規模の材料として使う。B−A は質問つき seed の上限寄りの見積りなので、製品の経路の差はこれより小さい可能性が高く、その場合の必要数は増える。

## 限界（10 節のうち結果に効くもの）

- **照合**：盲検を仕組みで守れない（文体・長さ・相対的な位置表現から arm を推測しうる）。Claude Code の system と tool が固定されない。原稿を読み切れない見落としが残る。judge と同系列（限界 18・19）。
- **較正**：判定者 1 人・42 件・arm あたり 6〜7 件、unsure 1。arm 0 は情報が少ない。arm 間の差への影響は見ていない。
- **自己選好**：抽出・IR・回答・Gold・judge・照合がすべて Anthropic 系列。IR の効果を過大に見せうる（限界 6）。
- **B−A の読み方に直結する限界**：（限界 2）B−A は文脈の量・検索単位と index・quote・要約文を同時に足し、分離していない。（限界 3）IR は全件承認済みで、却下・編集の無い最大条件。（限界 4）**文脈が製品の標準より薄い**（synopsis・codex・plot thread が空。A は story_so_far なしの下限）ので、**IR の増分が過大に見えうる**。（限界 5）m-ja-2 は model が記憶で答えうる。arm 0 の検出力は低く（上）、作品別を併記する。（限界 11）g-ja-1 は 11 Scene の IR が欠け、IR が答えられない質問が構造的にある（根拠 Scene の IR の有無で層別）。（限界 13）C・D は長文脈そのものと位置（p より前に限った効果）の交絡があり、C−A +79.4 などは arm だけでは分けられない。
- **IR は評価側が質問で選んだもの**（限界 16）：製品の経路との 8 件の重なりは平均 4.2／8、根拠 Scene の IR への収まりは 46％対 20％。B−A は上限寄り。IR は Chronicle の出来事だけ（限界 1）、描画は評価専用（限界 3）。
- **Scene の題が製品と違う**（本測定の後にユーザーの指摘で足した。事前登録の 10 節に無い）：評価の DB の写しでは、後の内容と位置の手がかりを除くため、Scene の題を中立のラベル（2 文字の片仮名。順位との相関は g-ja-1 0.04、m-ja-2 0.00。`relabel-record.json`）に置き換えた。回答はこのラベルで Scene を指すことがある。製品では本来の題が出るので、題が順序や内容を示す作品では、T（順序）などの質問が製品より答えにくい側に出うる。
- **回答の条件が製品の既定と違う**（限界 24）：effort は製品の chat が medium、pilot の Sonnet は high。定型句あり、history なし。棄権の絶対値は製品と違う（限界 9）。
- **judge**：根拠の段落だけを見る。誤りの flag は照合者と合わない（上記）。誤受理の測定は楽観的（限界 17・22・23）。本測定の judge の反復は未実施。
- **Gold**：人が確かめたのは答えのある 67 問のうち 30 問（誤り 1/30）。残りの 37 問と N の 12 問は未確認で、N の 1 問に誤りの疑い。M・U・K の網羅は見ていない（限界 7・20）。
- **規模**：cluster は 4、作品は 2。区間は広い（限界 8）。事実 QA は執筆支援の proxy（限界 14）。
