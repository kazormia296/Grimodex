# ユーザー確認：S2 予備測定の 6 問の選び方（2026-11-18）

- 伺った内容：予備測定（count_tokens・Haiku の反復・Sonnet の 12 回答）の 6 問について、記録の文言「Gold の先頭 6 問を ID 順」（p050-E1〜E4・K1・K2、全部 p050 で E／K 型だけ）と、q1 §6-3 の「各 point 3 問」が食い違う。先頭 6 問では往復数を少なく見積もるおそれがある。
- **回答：「各 point 3 問、M 型も混ぜる」**（推奨案）。
- 統合者の機械的な規則への落とし込み：**各 point（50・100）で、E・M・N の型ごとに ID 最小の 1 問**。
  - E＝記録の基準の型、M＝ユーザーの指定、N＝答えの無い型（探索が長く、往復数の高い側を見る）。
  - 6 問：p050-E1、p050-M1、p050-N1、p100-E1、p100-M1、p100-N1。Haiku の反復はその先頭 3 問（p050-E1・M1・N1）。
  - 規則は結果を見る前に固定し、結果を見て選び直さない。script（`s2-preflight.mjs` の `per-point-EMN`、既定）は、定数と規則の一致を実行のたびに確かめる。
- 範囲：質問の選び方だけ。送信先（Anthropic）・閾値・保存範囲・総額・段の上限は変えない。
