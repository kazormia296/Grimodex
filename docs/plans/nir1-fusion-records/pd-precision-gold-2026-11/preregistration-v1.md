## 4. 注釈

- 設問（2 値）：「**この Scene を、作者が今の Scene の執筆中に見たいか**」。今の Scene と候補の Scene の本文を見せる（製品の IR の解釈文・抜粋は見せない。§10）。
- 2 段（事前に固定。文面の案。確定時にユーザーが読む。§12）。各組に 0／partial のみ／strict を付け、strict なら partial も 1 とする。
  - **strict（1 つ以上に当たる）**：(a) 今の Scene と同じ人物が出て、その人物の行動・状態・関係が候補の Scene から続いている（同じ出来事の連続を含む）。(b) 今の Scene と同じ場所・物・設定が、候補の Scene で導入または変化している。(c) 候補の Scene に、今の Scene で回収・参照されている伏線・約束・秘密・出来事の原因がある（逆に、今の Scene が候補の出来事の結果になっている）。(d) 今の Scene を書くとき、候補の Scene の内容を知らないと矛盾や取りこぼしが出る。
  - **partial（strict ではないが 1 つ以上に当たる）**：(e) 今の Scene と主題・状況・感情の型が近い（同種の場面、似た対立、似た転機）が、人物・場所・出来事は連続しない。(f) 同じ人物が出るだけで、今の Scene の内容に関わらない。
  - どれにも当たらない（語彙や文体が似るだけ、登場人物も出来事も無関係）は 0。「見たい」は「書くときに参照して役に立つ」の意味とし、読み物としての面白さは問わない。
- 注釈者は**ユーザー**と **AI（OpenRouter 経由の `openai/gpt-6-luna`。既存の評価の harness の標準 model）**で、互いの値を見せず独立に付ける。model の id・版（OpenRouter が返す提供元と model の識別）・prompt（設問・上の類型の文面・出力形式）は測る前に固定し sha256 を記録する。同じ prompt を 2 回出し、1 回目を注釈、2 回目を安定性（AI 内の一致と κ）に使う。理由の文章は求めない。
- 一致：Cohen の κ と一致率を段ごとに（ユーザー対 AI、AI の 2 回の間）。不一致は消さず、件数を数える（調査文書による と、文学の注釈では絶対の閾値より段別の開示が妥当）。
- **主の注釈はユーザー**（案）。AI は副で、一致と、precision の幅（「両者が 1」「どちらかが 1」）に使う。
- 注意：調査文書による と、LLM が作る・付ける評価は人間より易しい側に寄る報告がある。AI の値がユーザーより高ければその向きで読み、AI だけで結論しない。

## 7. 判断規則（ユーザーの決定：(a)、L＝0.5、Δ＝0）

閾値の置き方はユーザーが (a) を選び（2026-11-06）、下限 L を 0.5、相対の許容差 Δ を 0 とした。(b)（絶対値だけ）は選ばれなかった。測る前にこの文面で固定する。

- **IR の rank r が通る条件**（r＝1、2、3 のそれぞれ。両方を満たすこと）：
  1. **相対**：IR の rank r の strict precision の点推定が、同じ query の Raw の rank 6〜8（合計）の strict precision の点推定を**下回らない**（Δ＝0）。差の区間（query 単位の bootstrap）も併記する。
  2. **下限**：IR の rank r の strict precision の Wilson 95％ 区間の下端が **0.5 以上**。n＝60 なら点推定で約 0.63（38/60）が要る。n が少ない rank は必要な点推定が上がる（n＝30 で 0.70）。
- **枠の数**：rank 1 から順に条件を調べ、**連続して両方を満たす最大の k** を採用候補の枠の数とする（rank 2 が通らなければ、rank 3 が通っても k＝1）。k＝0 なら増やさない。8 超の arm（O1／O2）も、足す件数 k を同じ条件で決め、上限を外すかどうかは別にユーザーが決める。
- 参考値（A5 比較 1 の英語の校正 precision 0.769、holdout 0.667）は IR 1 件の過去の値で、条件の根拠にしない。
- **判断不能（D0 相当）の案**（値は推奨。確定時に確認）：次のどれかなら、結論を出さず「判断不能」と書く。(1) 有効な query（候補を取れ、注釈が揃った query）が **40 未満**、(2) ユーザーと AI の strict の κ が **0.4 未満**（設問が割れている）、(3) その rank の注釈済みの組が **30 未満**、(4) 候補を取れなかった query が 10％ 超。
- 注意：Δ＝0 は点推定どうしの比較で、n が小さいと偶然で動く。通る・通らないは区間を併記して読み、条件を満たしても「採否の決定」ではなく、ユーザーが結果を見て決める材料とする。
- ここの条件は採否の判断用で、第 5・6 版の D0・D1、IR の floor、既存 Gold の期待値は変えない。
