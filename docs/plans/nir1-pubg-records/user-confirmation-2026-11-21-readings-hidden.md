# ユーザーの確認（2026-11-21、AskUserQuestion）：Codex の hidden の項目の読みを AI で推定するか

- 背景：IME の読みの推定は、Codex の hidden（AI に秘匿）の項目の名前と別名を AI に送っていた。対象は、設定の「読みの一括推定」と、項目ごとの「AIで推定」の両方。本文や概要は送らない。
  - 調査：`fusion-eval-data/design-notes/parallel-abc-2026-11-21/journal.jsonl` の A。
- 一括推定から hidden を外すことは、2026-11-20 に確認済み（ADR 013 の確認 4、contracts `11dc9eda`）。
- 項目ごとのボタンについて、ADR 013 の書き方は分かれていた。
  - :126 は「読みは作者が手で入れるか、個別に推定する」と書き、個別の推定を許す書き方。
  - :62・:81・:282 と画面の文言は「hidden はどの経路でも AI に渡りません」。
- 問い：hidden の項目で、作者がその項目の画面の「AIで推定」を押したときも、AI に送ってよいか。
- 回答：**ボタンでも送らない（推奨）**。
  - 画面の文言「hidden はどの経路でも AI に渡りません」と揃える。
  - hidden の項目では「AIで推定」を使えないようにし、読みは作者が手で入れる。
  - ADR 013 の :126 の「個別に推定する」は、この回答に合わせて直す。
