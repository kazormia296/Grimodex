## 0. 何を決める案か

/1 の C5 は、確度が「不明」の出来事を、生死の計算の材料にしない。そのため、誕生が分かる人物の死亡の出来事の確度が「不明」だと、死亡が無いのと同じになり、AI に「存命」と渡る。これを「不明」にする。

## 1. 確かめた事実

- 生死の導出は 2 か所にある。アプリ内の AI 向けの `deriveCharacterStateAt`（`electron/shared/readDomain/features/chronicle/chronicleSnapshot.ts`）と、MCP の `derive_character_state_at`（`src-tauri/crates/grimodex-mcp/src/chronicle_snapshot.rs`）。どちらも、確度が「不明」の誕生・死亡の出来事を飛ばし、誕生が現在地以前で、使える死亡が現在地以前に無ければ「存命」にする。【読んだ】
- 生死の値「不明」は、今もある（誕生が分からないとき）。自動のまとめには「名前: 不明」と出て、年齢は出ない。道具と MCP の返り値にも同じ値が入る。【読んだ】
- 確度が「不明」として扱う死亡の出来事は、次のものである。作者が確度を「不明」にしたもの。移行（版 49）が日時を入れた、日時の無かったもの。抽出の取り込みで Native が日時を入れたもの（/1 の G6。取り込みは今は閉じている）。取り消しや復元で戻った、日時の無いもの（/1 の B1）。日はあるのに粒度が空の行（2026-07-29 より前の版の AI・MCP の作成で起きうる。移行が粒度を直す。移行の後に、移行前の状態を復元すると残る）。【読んだ】

## 2. 規則

用語：「確かな死亡」は、その人物が主な人物の、種類が「死亡」の出来事で、日時があり、確度が「確定」か「おおよそ」のもの。「不明の死亡」は、同じく種類が「死亡」で、確かな死亡でないもの。

- **L1**　生死と年齢の計算の材料は、/1 の C5 のままにする。不明の死亡の日は、計算に使わない。
- **L2**　誕生が分かり、現在地が誕生以後の人物は、次の順で決める。
  1. 確かな死亡が 1 件でもあれば、確かな死亡だけで、今と同じに決める（最も早い確かな死亡の日が現在地以前なら「故人」、後なら「存命」）。不明の死亡は見ない。（◇2）
  2. 確かな死亡が無く、不明の死亡が 1 件でもあれば、生死は「不明」にする。不明の死亡の日が現在地より後でも、「不明」にする。（◇3）
  3. どちらも無ければ「存命」にする。
- **L3**　L2 の 2 で「不明」にした人物の年齢は出さない。（◇4）
- **L4**　不明の死亡には、日時の無い死亡と、日はあるのに粒度が空の死亡も数える。（◇5）
- 変えないもの：誕生が分からない人物は「不明」。現在地が誕生より前の人物は「未誕生」。現在地が決まらないときは「不明」。整合の検査（因果、二か所に同時に居る、年齢、季節）、出来事の前後、「作中の現在地」、画面の表示。アプリ内の道具の説明文。

## 3. 残る制限（/1 の §3 の該当の項を置き換える）

- 確度が「不明」の死亡がある人物は、確かな死亡が無ければ、誕生の後のどの場面でも、生死が「不明」になる。移行や取り込みが入れた仮の日時の死亡でも同じで、作者が死ぬ前と考えている場面でも「不明」になる。作者が、死亡の出来事の確度を「確定」か「おおよそ」に直すと、日で「故人」か「存命」を決める。
- 版を上げる前から日時が無かった死亡の出来事を持つ人物は、今は「存命」で、移行の後は、確かな死亡が無ければ「不明」になる。
- 「不明」の理由（誕生が分からない、死亡が不確か）は、AI に区別して渡らない。
- L3 の年齢は、まとめと状態の道具が返す、現在地の人物の年齢である。人物の年表の道具が出来事ごとに返す年齢（`ageAtEvent`）は変えないので、不明の死亡の出来事にも、今までどおり値が付く。
- 確度が「不明」の出生の出来事だけを持つ人物は、今までどおり（/1 のまま）「不明」である。

## 4. 脅威モデル

変えない。actor、受け手、保存先、送信先、権限を足さない。渡る生死の値は、今ある 4 つ（存命、故人、未誕生、不明）のどれかで、欄を足さない。

## 5. 受入れ

- アプリ内の AI 向けと MCP が、同じ共有の例（`src/features/chronicle/fixtures/chronicle-snapshot/`）で、同じ値を返す。
- 次の例を固定する：不明の死亡の日が現在地より前と後（どちらも「不明」、年齢なし）。確かな死亡と不明の死亡の両方（確かな死亡で決まる）。日時の無い死亡と、粒度が空の死亡（「不明」）。不明の死亡が無い人物（今と同じ値と年齢）。誕生より前の場面（「未誕生」）。
- 起動時の JS が上限を超えるときは、CI の実測に 256 byte を足した値まで、独立した commit で上げる（確認 164。この直しに限る）。
