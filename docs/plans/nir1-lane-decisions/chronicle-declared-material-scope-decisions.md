この lane は、NIR-1 の残レーンの委任の外である。規則、脅威モデル、残る制限は、ユーザーが個別に確認した。下の判断は、確認された本文の範囲内の技術判断である。

## PR の分け方と止める点

- 1 つの PR にする（画面側の記録の作り方、保存の前の検査、試験と正本）。Native の製品コードは変えない。
- 絞った記録の提案を、Native の保存、材料の再生、資格の判定、取り込みまで実際に通す。**通らない検査が見つかったら、実装を止めて報告する。** Native の変更が要る場合は、別に伺う（設計の §8）。
- MW/1 の実装の後に merge する（D9）。

## 判断

| ID | 判断 | 理由 |
| -- | ---- | ---- |
| DR-DMS-1 | 絞る単位は、次の順で決める：その提案の出来事にまとめられた観測の全部（合成の要求に入った観測）→ 各観測の番号の先頭にある区切り → 区切りの計画が指す文書 → その文書の材料の項目。Native の下限の検査と、同じ引き方である | D1、D2。画面側と Native が、同じ規則で場面を決める |
| DR-DMS-2 | 抽出 1 回の材料の一覧を作る関数は変えない（人物・設定の抽出も使う）。提案ごとの記録を作るところで、一覧から、元の順を保って選び出す。抽出の封印の項目は残す | D4、D6、D7。場面 1 つの抽出で、値が今と同じになるようにする |
| DR-DMS-3 | 区切りの計画を、提案の記録を作る段に渡す。保存済みの記録から読む（再開のときも同じ経路で読める） | 今は、その段に区切りと文書の対応が渡っていない |
| DR-DMS-4 | 依存の宣言は、絞った一覧から作る：根拠の場面は「直接の根拠」、絞った範囲の残りの場面は「用途を限定できない model の文脈」。絞った範囲の外の場面は、宣言しない | D1。宣言の種類は今と同じで、範囲だけが変わる |
| DR-DMS-5 | 保存の前に、画面側で次を確かめる。満たさなければ、その抽出の提案の保存を止める：観測の番号から区切りと文書を引けること。その出来事の観測の全部の場面が、記録に入っていること。提案の根拠の場面が、記録に入っていること。止める単位は、抽出の全体とする | D3。今のコードでは起きない見込みの防御である。試験で固定する |
| DR-DMS-6 | 絞るのは、今の形式（V2）で、AI を使う抽出の提案だけである。古い形式の予備の経路は、抽出の全部の場面のまま残す | D7。古い形式は、関連場面の対象に入らない |
| DR-DMS-7 | 観測の要求と合成の要求について、実際に送る値が、記録する値と同じであることを、試験で固定する。確かめていない送信の経路（Responses、Ollama、AI のべりすと）が、記録に無いものを足していないかを読み、足していれば報告する | 設計の §4 の「残る信頼の前提」、§8 |
| DR-DMS-8 | 絞った記録の形の正本を、新しく作る：画面側が作った記録を、Native の材料の再生と資格の判定まで通す。今ある区切り 2 つの正本（抽出の全部の場面を宣言する形）は、古い形の抽出を読む試験として、そのまま残す | D5、D8。読む側は変えないので、古い形はそのまま読める |
| DR-DMS-9 | 試験用のデータは、3 場面のフォルダの抽出を、通常の抽出の経路で作る。場面をまたいで観測がまとまる出来事を含める。MW/1 の試験用のデータと、同じものを使えるなら使う | D8 |
| DR-DMS-10 | 範囲外：Native の製品コード、材料の再生の条件、読む側で材料を縮めること、既に保存されている提案の記録の書き換え、修復が走った抽出、フォルダを場面ごとに抽出する操作 | 候補を小さく保つ |

## 信頼境界と影響

| 面 | 影響 |
| -- | ---- |
| 材料の記録（画面側が作る） | フォルダの抽出で、抽出の全部の場面から、その提案の出来事の観測が出た場面に狭まる。場面 1 つの抽出では変わらない |
| Native の下限の検査 | 変わらない。合成の要求に入った観測の場面が宣言に無ければ、関連場面に出さない。走るのは、関連場面に出すときだけである |
| 関連場面（IR） | 判定は変わらない。フォルダの抽出の提案が、出来事の観測の場面より後ろから見えるようになる |
| 鮮度と取り込み | 関係のない場面の編集では、古くならず、取り込みも止まらない |
| 残る信頼の前提 | Native が確かめるのは、画面側が記録した要求である。同じ抽出の中でも、この前提に依るようになる。防御は DR-DMS-7 |
| 既に保存されている提案 | 変わらない |
| 評価 | 場面ごとの抽出では、記録は変わらない。凍結した定義と Gold は変えない |

外部への送信、subprocess、保存先、IPC は変えない。
