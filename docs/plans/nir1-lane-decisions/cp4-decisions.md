# CP-4 の委任判断の記録（継続計画 §3.2 の形式）

CP-4 は、Graph arm（R+IR+Graph）を初めて実 Electron と実 Native で観測する計測 lane である（TASK `cp4-task.md`。§15「integrator 追記」が §0〜§14 に優先する）。この文書には subtask ごとの節を足す。共通の判断（DR-CP4-0〜、TASK の D1〜D16、threat model、owner/lifecycle の matrix）は integrator が書く。記録済みの行は直さず、後の変更は各節の「実装後の追記」に足す。

閉じたままのもの（CP-4 のどの subtask も変えない）：`PRODUCT_GRAPH_PUBLISHED=false`、`NIR1_GRAPH_UI_ENABLED=false`、`BODY_DECLARATION_UI_ENABLED=false`、`PrePublicationEntry::ProfileActivation`（既定で閉）、`PROFILE_ACTIVATION_UI_ENABLED=false`。確認済みの値（D=10.84 ms、100 ms の lease、K1／proposal/7 の上限、1%、Gold、fixture、`evals/nir1-graph/freeze.v1.json`）も変えない。

## S1a（Native の評価専用 feature。TASK D8、D9、D11 の Native 側、§15.2、§15.3、§15.9）

S1a の行の ID は、同じ文書に S1b が足す行と衝突しないように `DR-CP4-S1A-n` とする。行は S1a の実装と並行して書き、実装と同じ branch の、実装より前の commit に置いた（厳密な「mutation の前」ではない。判断の中身は TASK §15.3 の方式の具体化である）。
