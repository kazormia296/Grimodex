- 発端：CP-4 S1j-2 の実機の記録（`claude-cp4-s1j2` の `cp4-decisions.md` の DR-CP4-L-8、L-12、L-13。run は `.artifacts/cp4/s1j2-p0-all`、`s1j2-p0-b2`、`s1j2-p0-c2`、`s1j2-p1-1`〜`-5`、`s1j2-dev-8`、`s1j2-dev-10`。読んだだけ）。

| DR-BSEAM-2 | **修正**。grimodex-db に `discover_maintenance_project_for_main`（Main の discovery の project ごとの判定）と `nir1_graph_index_build_wakes_main_discovery`（cycle と同じ `Nir1GraphIndexBuildGate::from_journey_seam` に before-cutover の除外を足しただけ）を置き、native `discover_all` がそれを使う。gate が開いているときだけ、(a) durable が `None`、(b) durable が `ValidationTerminated(ContextUnavailable)` のとき、その project を `wakeProjectIds` として返す。Main は空の work の cycle（既存の `wakeProjectIds` の wire）を送り、Rust の cycle が制御つきで B を判定し（dirty は durable chain より先に作り直す）、durable chain も自分の validation context で判定し直す。Main は B を名指ししない（`normalized_work` の拒否は不変）。Electron：coordinator は bootstrap が B-ROUTE の seam のときだけ渡す `acceptGraphIndexBuildWakes` で `wakeProjectIds` を受け、scheduler の `requestGraphIndexBuildWakesWithBinding` が discovery の binding に束ねた wake を登録する。work が空なら chain は従来どおり終わるので、clean な B で rediscovery が回り続けない（wake 1 回につき cycle 1 回）。seam の説明（`narrativeMaintenanceCiSeam.ts:74-77`）を実態に合わせた | actor：Native（project の列挙と判定）→ Main（wire の検証と queue）。wake の project ID は Native が DB から列挙した値だけで、renderer／preload／IPC は関与しない。保存範囲、外への送信、新しい authority、新しい gate は無い。開けられる条件は既存の B-ROUTE の gate と同じ（未 package、`CI=true`、owner token、trigger。nonce は TS の seam の parse で必須） | (A) discovery で B を判定して work を返す：判定に cycle の owner と runtime が要り、Main に gated の kind を名指しさせる（`normalized_work` の不変条件を緩める）ので不採用。(B) discovery を full-eligibility の制御つきにする：discovery に cycle の owner が無く、制御の範囲が広がるので不採用。(C) harness の待ちを延ばす／開き直す：DR-CP4-L-12 の実機で効かなかった | 試験で固定：seam なし、packaged、`CI` 不一致、owner 不一致、他の trigger（trigger null を含む）のそれぞれで、`discover_maintenance_project_for_main` の答えと error が従来どおり（idle なら `Idle`、sealed なら context-unavailable の error のまま）、Main の経路で cycle 0 件、native の wire が byte 同一（`wakeProjectIds` の key が出ない）、coordinator は wake の key を invalid response として拒み、bootstrap は従来の 2 引数で coordinator を作る。nonce が無い／不正なら seam が active にならない | 実装済み（`3b66f157`、`7d73e253`） |
