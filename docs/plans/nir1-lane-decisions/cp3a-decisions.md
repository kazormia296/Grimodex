# CP-3a の委任判断の記録（mutation の前に記録。継続計画 §3.2 の形式）

出所の確認済み契約は K2/4（`docs/plans/nir1-c-body-disclosure-proposal-4-draft.md`。`graph-target-scene-body-disclosure` と `scope-storage-authority`。2026-10-17 の Session B2 で確認済み）、K3/2（`nir1-publication` の区分と event の表。2026-10-17 の Session B1）、K1（Graph の `2hop／12／144／8`）、DSN（Related Scenes と Graph の設計メモ）である。この文書は subtask S1（db crate の再検証）の mutation の前に書く。S2a／S2b（Native）、S3（IPC と Main）、S4（renderer）の判断は、各 subtask の実装の前に同じ形で追記する（後から本文を直さない）。

U3 の委任（継続計画 §3.1）の外に当たる要素は、S1 の範囲に無い。新しい受信先、保存範囲の拡大（schema、table、列）、確認済みの閾値の緩和、製品入口の公開、認可の削除、新しい authority のどれも置かない。S1 は grimodex-db の pure な同期関数と型、budget 付きの read transaction の入口だけを足す。IPC、preload、N-API、Main の route 台帳、gate、grant、`PRODUCT_GRAPH_PUBLISHED` は変えない。入口は `native-current-human-capture` の feature の内側にだけ置き、MCP は有効にしない。

## owner/lifecycle matrix（GDX-PRECHECK-001）

S1 は不要。S1 は egress、subprocess、background、async lifecycle を変えない。足すものは、呼び出し側が開いた participant の read transaction の中で呼ぶ同期の関数と、その transaction を budget 付きで開く入口（既存の `with_participant_read_transaction_bounded` の薄い公開 wrapper）だけで、thread、timer、cache、永続の記録、process-local の状態を作らない。budget の progress handler は transaction の中だけに入れ、抜けるときに必ず元の owner を戻す（DR-CP3A-7）。S2a 以降が owner/lifecycle の matrix（TASK §10）を追記する。

## S3 の owner/lifecycle matrix と threat model（GDX-PRECHECK-001。S3 は route と検証だけ）

owner/lifecycle matrix は不要。S3 は Main の route 台帳、allowlist、検証、`events.ts` の guard だけを足し、thread・process・timer・cache・保存・外向きの通信・Native の新しい入口を作らない。Graph の owner、待受け、取消の lifecycle は S2a の matrix（上）のままで、S3 はその入口の手前（Main の検証と束縛）に立つ。

threat model（新しい信頼境界はない）。(1) 壊れた・過大な入力：Main が形を絞り（DR-CP3A-33・34）、Native が再検査する。(2) 別 owner の ticket を指す：Main が owner を束縛し、Native が一致を確認する（DR-CP3A-37）。(3) 権限のない呼出し：restricted で identity が無い・回転した・activation の途中・gate の unavailable は invoke の時点で拒否、完了時に回転していれば応答を捨てる（DR-CP3A-35）。(4) event の偽造：renderer は emit できず（backend allowlist だけ）、payload は `{ projectId }` だけで、他は Main が捨てる（DR-CP3A-36）。(5) Graph の公開：S3 は PUB-G の bool も Native の gate も変えない。seed を送る production の renderer の呼出しは S4 も作らないので、この入口は閉じたまま inert（Native が `not-activated`／`profile-not-restricted` を返す）。
