## S1 で確かめたこと

- `SOURCE_IDENTITY_PREFIXES`／`source_identity_prefix_for`／`validate_stored_source_object_identity`／`infer_source_kind`／`resolve_source_revision` が同じ集合を扱うこと（登録の網羅の試験）。
- 投影の単体試験、key の文法、MISSING／STALE／PROJECT_MISMATCH の分類、実 writer（`update_narrative_scene_scope`、`update_narrative_scene_scope_registry`、`tree_node_patch`、`tree_node_delete`）に対する token の変化・不変・往復。
- routing（`affected_source_identities`）と `pending::read` の試験。
- 型付き Revision の writer と reader はまだ変えない（S2）。

## S2 で確かめたこと

- 新しい Revision の material basis は anchor ごとの投影の行（`scene-scope-projection-v1`）、dependency `nir1:scope:<sceneId>`、component contract 版 2（`nir1:component-contract:2`）。`project-scope-authority` の行は入らない。
- 版 1 の Revision（test 専用 builder）、混在 basis、未知の版は unavailable で、行は不変。
