# CB-3 の委任判断の記録（mutation の前に記録。継続計画 §3.2 の形式）

出所の確認済み draft は K2/4（`docs/plans/nir1-c-body-disclosure-proposal-4-draft.md`。`graph-target-scene-body-disclosure` と `scope-storage-authority`。2026-10-17 の Session B2 で確認済み。K2-3 は取消の入口に grant を要さない）。この文書は S1（Native の宣言状態の読取。grimodex-db）の mutation の前に書く。S2（Native の入口と契約）、S3（renderer の論理）、S4（UI・文言・実 Chromium の試験）の判断は、各 subtask の実装の前に同じ形で追記する。実装で変える場合は、後から本文を直さず追記で理由を書く。

U3 の委任（継続計画 §3.1）の外に当たる要素は、この lane の範囲に無い。新しい受信先、保存範囲の拡大（schema、table、列）、確認済みの閾値の緩和、製品入口の公開、認可の削除、新しい authority のどれも置かない。固定されていて変えないもの：宣言の writer と取消の writer、grant の種類、gate（`PrePublicationEntry::SceneBodyDeclaration`）と CI seam、schema と v1 の列、宣言の 2 列の意味、CB-4 の reader、Related Scenes（CP-3a／b）、`scene_body_declaration/facts.rs`（writer と preview の拒否の順序）。読取は宣言の 2 列と v1 の列、feed、idempotency、`tree_nodes` を書かない。読取は `native-current-human-capture` の feature の内側にだけ置き、MCP は有効にしない。

## owner/lifecycle matrix（GDX-PRECHECK-001）

S1 は egress、subprocess、background、async lifecycle を変えない。読取は、既存の participant の bounded read transaction の中で呼ばれる同期の関数で、thread、timer、cache、永続の記録、process-local の状態を作らない。接続と participant の保持・放出は `preview_scene_body_declaration` と同じ作法のままで、新しい数値（mutex 100 ms、busy 100 ms、操作 250 ms、本文の読取の上限）は足さない。renderer 側の非同期（hook、epoch）は S3 で matrix を追記する。

## threat model（GDX-PRECHECK-001 の security-sensitive。要点。全文は TASK §11）

- 守るもの：Scene の本文・title・digest・locator。応答に載せるのは閉じた集合の状態と、OCC に要る不透明な token 3 つ（scopeVersion、scopeToken、declarationToken）だけ。
- 信頼しない：renderer の全て。UI は安全の根拠にならず、害の防止は Native と Main が担う。読取は書かない。
- S1 が受け持つ行：読取の応答から本文・title・digest・locator・Graph の到達が漏れる（型に欄が無い。N-5）／読取の副作用（read-only。N-6）／壊れた cell（closed な `unavailable`。N-7）／quarantine（DB を読む前に `restart-required`。N-8）／処理の途中の中断（`Err`。部分的な結果なし。N-9）／UI が「無効」と見せながら reader が開示できる状態（P2-2 の整合の試験）。
- 範囲外として受け入れる残余（draft の Out-of-scope）：乗っ取られた renderer が取消・本文の再保存などで開示を止めること（可用性）。renderer が表示した title や状態を利用者の入力として送ること。CI seam の env を設定できる者がダイアログなしに承認できること。

| reentrant | 操作中（`busy`）は宣言・取消のボタンを無効にする（hook も二重を拒む）。確認欄は読取と操作の間は触れない |
| admission closure | form は Scene の切替と unmount で消え、確認を捨てる（`key` と mounted の ref） |
| pending-start work | なし。`useUnsavedSceneEdits` は zustand の購読と `pendingSynopsisSaves` の listener だけ（unmount で解除）。timer も background も新設しない |
| active handle | 購読の解除関数だけ |
| cancellation | 遅れた結果は hook が捨てる。確認の state は mounted の ref で unmount 後に書かない |
| bounded wait | 宣言は Main の確認の 60 秒（待つ間は「確認ダイアログを待っています」と無効化）。未保存の待ちは保存が終わるまで（自動の flush なし） |
| 終了の証拠 | hook の `busy` が応答か error で必ず戻る。form は結果の後に確認を捨てる |
| error／timeout／onClosed | closed code の文言。生の message を出さない |
| restart | 何も永続しない（storage、log、undo のどれにも書かない） |
