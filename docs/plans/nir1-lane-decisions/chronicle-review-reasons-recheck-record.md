# 見せる理由の条件：開ける前の確かめの記録（RR/1）

台帳の RR/1（`nir1-chronicle-review-reasons-proposal/1#chronicle-apply-secret-projection`）は、条件を製品で開ける前に、「AI の再判定と少数の抜き取り」で確かめると決めている。この文書は、その確かめの結果と、ユーザーの判断の記録である。契約の確認ではない。

## 何を確かめたか

- 対象：第 6 版の IR の評価の 2 作品（g-ja-1、m-ja-2）の提案 1,435 件のうち、条件 R1〜R4 のどれも付かない 1,086 件。「まとめて承認」の対象になる提案である。抽出は、この全件を「作中の現実・地の文」と分類している。
- 問い：その出来事は、場面の中で起きたことか。それとも、誰かの発話・伝聞・回想・夢・仮定の中で語られた、別の出来事か。
- 方法：題、要約、根拠の引用、引用の前後 300 字の本文を渡し、抽出のときの分類は見せずに判定させた（Sonnet の subagent、1 回の依頼に 110 件）。出力の id は、入力と全件一致した。挙がった件は、統合者が全件を読んだ。
- 2026-11-11 に実施。入力と出力は repo の外（評価データの置き場の `design-notes/review-reasons-2026-11-11/`）にある。原稿の本文を含むので、repo には置かない。

## 結果

| | 件数 |
| -- | -- |
| 場面の中で起きたこと | 1,075 |
| 発話や手紙の中で語られた別の出来事 | 9 |
| 伝聞 | 1 |
| 推量（仮定） | 1 |
| 合計 | 1,086 |

- 場面の中で起きたことではないと判定されたのは 11 件（1.0%）である。作品別は m-ja-2 が 7／410 件、g-ja-1 が 4／676 件。
- 11 件は、統合者が読んだかぎり、どれも判定が妥当だった。内訳は、人物が語る過去の経緯（7 件）、手紙の中身（2 件）、「〜とのこと」という聞いた話（1 件）、語り手の推量（1 件）である。
- 判定の確信は、高が 1,041 件、中が 45 件だった。

## 1 回目の確かめの取り下げ

最初の確かめは、86 件（7.9%）を挙げた。これは取り下げた。統合者が判定に渡した定義が、製品の抽出の指示（`src/application/narrative-extraction/aiTasks/observationPromptGuidance.ts`）より広かったためである。

- 「回想」に、地の文が事実として述べる直前の経緯の説明を含めていた（26 件）。
- 「発言の中」に、話す行為そのもの、つまり会話の場面を含めていた（44 件）。製品の指示は「人物が話した行為と発話内の内容を混同しない」と定めている。

ユーザーの指摘（「食い違いが発生しているようには見えない」）で分かった。2 回目は、問いを上の 1 つに絞り、話す行為、その場の内面の動き、地の文の経緯の説明を「場面の中で起きたこと」と明記した。

## ユーザーの判断

2026-11-11、11 件の一覧を見たうえでの回答（逐語）：「まとめて承認に入って構いません」。

- 誰かの話や手紙の中で語られた出来事が、条件の付かない提案に約 1% 混じることを承知のうえで、「まとめて承認」の対象に入れてよい。
- 条件 R1〜R4 と R0 は変えない。
- RR/1 の「開ける前の確かめ」は、これで済みとする（統合者の読み）。「まとめて承認」の実装と、製品での開放の手順は、別に進める。

## 限界

- 2 作品（うち 1 作品は AI が書いた原稿）の、1 場面ずつ抽出した形の値である。製品の経路の値ではない。
- 再判定も AI の判定である。挙がらなかった 1,075 件の中の見逃しは、統合者が読んで確かめていない。
- 条件の付いた 349 件が、個別に見る価値のある提案かどうかは、確かめていない。
