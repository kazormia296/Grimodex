## 0. 一枚目

**何を決める案か。** AI に年表の出来事を渡すとき、今書いている場面から見て「これまで」の出来事か、「これから」の出来事かを、区別して渡す。あわせて、今の場面の作中の日時と、視点の人物を、はっきり渡す。

**なぜ要るか。** SRA/1 で、承認した出来事を、秘密の印なしで年表に入れることになった。位置で絞ることはしない。AI が道具で年表を引くと、先の出来事も渡る。絞らない代わりに、前後の区別を渡す。

**形**
1. AI が道具で引く出来事の一覧・詳細・検索は、出来事を除かない。1 件ずつ、位置の印を付ける。印は、「これまで」「今の場面」「同時進行」「これから」「不明」の 5 つである。印は、出来事の日時と、今の場面の「作中の現在地」を比べて決める（CED/1）。
2. 道具の返り値に、今の場面の題と、作中の日時を足す。
3. チャットに自動で入る年表のまとめは、見出しを「これまでの主な出来事」にする。作中の日時が決まらない場面では、「未確定」と書く。
4. 場面に設定した視点の人物を、「この場面の視点」として渡す。
5. 自動のまとめに「これからの出来事」の欄を足すかは、小さな測定の結果を見てから決める。

**変えないこと**
- 作者が付ける印（Codex の hidden、年表の出来事の秘密の印）の判定は、変えない。位置の印は、その判定の後に付ける。
- 自動のまとめに入れる出来事の考え方（「これまで」の出来事、未回収の因果、本文未描写の背景）は、変えない。比べ方は、CED/1 で変わる。
- 場面ごとの時制の設定欄は、今回は足さない（起案者の提案。ユーザーは「場面ごとの時制を渡す」を選んだうえで、「渡さなくてもなんとかなるかも」と添えた。◆5 で伺う）。現実の今日の日付は、渡さない（選ばれていない）。
- MCP の出来事の一覧には、位置の印を付けない。

## 1. 確かめた事実

### 1.1 ユーザーの決定（2026-11-22）

1. 承認して年表に入れた出来事に、秘密の印を付けない。位置の絞りは足さない（SRA/1）。
2. 「『これまで』と『これから』を区別し、また今の日時、時制、等を渡す必要が有るかもしれません」（発言の原文）。
3. 位置の区別は、「道具の一覧にも公開の前に入れる」。選択肢の説明は、「道具で引く出来事の一覧・詳細・検索にも、1 件ずつ『これまで／これから／不明』の印を付ける。道具を作り直している別の作業と同じ場所を触るので、調整が要る」という内容だった。
4. 日時と時制は、「作中の日時をはっきり書く」「場面の視点の人物を渡す」「場面ごとの時制を渡す」を選び、「場面ごとの時制はシーンの作中日時がはっきりすれば渡さなくてもなんとかなるかも？分からないですが」と添えた。「現実の今日の日付を渡す」は選ばなかった。
5. 自動のまとめには、「これから」の出来事も、印つきで入れる。作者が印を付けた出来事は入れない。
6. 「これから」の欄については、小さな測定を先に行う。欄がある場合と無い場合で、AI の返す文章に先の展開がどれだけ出るかを比べ、結果を見てから、入れるかどうか・件数・指示の文を決める。欄の実装は並行で進める。測定の手順と費用は、始める前に見せる。
7. MCP の一覧への位置の印は、公開の後に、別に起案する。
8. 出来事は必ず日時を持ち、前後は日時で比べる。確度が「不明」の出来事は、「作中の現在地」の材料にしない。出来事が全部「不明」の作品だけは、材料にする（CED/1 の決定 8・10）。
9. 今の場面と同じ日時の出来事は、「これまで」でも「これから」でもなく、同時進行として扱う（CED/1 の決定 9）。

起案者の提案（2026-11-22 に、まとめて確認いただいた。§5）：印の値「今の場面」。自動のまとめの見出しを「これまでの主な出来事」にし、件数の上限で選んだ一部であることを、導入の文に足すこと。自動のまとめに「同じ頃の出来事」の欄を設けること。人物の年表と、年表の状況を読む道具にも印を付けること。場面ごとの時制は、設定欄を足す前に、作中の日時と位置の区別を入れて、なお要るかを見ること。

## 2. 規則

### 2.1 位置の印（W1〜W5）

- **W1**　位置の印は、次のどれかである。「これまで」「今の場面」「同時進行」「これから」「不明」。
- **W2**　今の場面に結び付いた出来事は、「今の場面」である。
- **W3**　それ以外の出来事は、出来事の幅を、今の場面の「作中の現在地」の幅と比べる（CED/1 の K2・C4）。全部が前なら「これまで」、全部が後なら「これから」、重なるなら「同時進行」である。手前の場面から現在地を借りた場面では、「同時進行」を使わず、重なる出来事を「これまで」とする（CED/1 の K2a）。
- **W4**　「作中の現在地」が決まらない場面と、場面が開いていないときは、今の場面に結び付いた出来事を除いて、全部「不明」である。日時の無い出来事（取り消しや復元で戻ったもの。CED/1 の B1）も、「不明」である。
- **W5**　位置の印には、出来事の確度を添える（CED/1 の C1）。確度が「不明」の出来事の印は、前後が不確かである。判定は、CED/1 の比べ方の関数と同じ file に置く。

### 2.2 自動のまとめ（M1〜M5）

- **M1**　入れる出来事の選び方は、CED/1 の比べ方に通す。「これまでの出来事」には、印が「これまで」か「今の場面」の出来事を入れる。「未回収の因果」と「本文未描写の背景」は、今と同じ考え方である。
- **M1a**　印が「同時進行」の出来事は、「同じ頃の出来事」という欄に分けて入れる。今は、同じ日の出来事は「これまで」に入っている。送る出来事の種類は、増えない。件数の上限は、「これまで」と合わせて、今の上限のままにする。欄の導入の文に、「今の場面と同じ頃に進んでいる。前後は決められない」と書く。
- **M2**　見出し「直近の出来事」を、「これまでの主な出来事」にする。導入の文に、次の趣旨を足す。「ここに並べた出来事は、件数の上限で選んだ一部である。ここに無い出来事が、起きていないとは限らない。」日本語と英語の両方を直す。
- **M3**　現在地を、確度が「不明」の出来事で決めたとき（CED/1 の C3a）は、作中の時刻に「日付は不確実」と添える。作中の現在地が決まらない場面では、「作中時刻: 未確定」と書く。書くのは、まとめにほかの行が 1 つでもあるときだけである。ほかに何も無ければ、今までどおり、まとめを出さない。手前の場面から借りたときは、今までどおり、推定であることを書く。
- **M4**　件数の上限と、大きさの上限は、変えない。
- **M5**　「これからの出来事」の欄。入れるかどうか、件数、添える指示の文は、測定（§4.2）の結果を見せてから、ユーザーが決める。それまで、master には入れない。測定に使う形は、次のとおりである。印が「これから」の出来事を、今の場面に近い順に、最大 4 件。秘密の印のある出来事は、開示の後でも入れない。確度が「不明」の出来事は入れない。「今の場面では、まだ起きていない。起きたこととして書かない」という指示を添える。

### 2.3 道具（T1〜T5）

- **T1**　出来事の一覧・詳細・検索に、位置の印を付ける（決定 3）。人物の年表と、年表の状況を読む道具にも、同じ判定で付ける（起案者の提案）。
- **T2**　出来事は除かない。出来事 1 件ずつに、位置の印を足し、確度（CED/1 の C1）と並べる。
- **T3**　印の基準は、道具を呼んだ時点で開いている場面である。年表の状況を読む道具は、渡された場面を基準にする。
- **T4**　一覧・詳細・人物の年表の返り値に、基準の場面の題と id、作中の日時、現在地の出どころ（場面の日付・結び付いた出来事・手前の場面からの推定・不確実な仮の日時・未確定）を足す。検索の返り値は、並びのままにし、1 件ずつの印だけを足す。
- **T5**　印の読み方を、道具の説明に書く。「これまで」は、今の場面より前に起きた。「今の場面」は、この場面に結び付いた。「同時進行」は、今の場面と同じ頃に進んでいて、前後は決められない。「これから」は、今の場面では、まだ起きていない。「不明」は、前後が決められない。自動のまとめが省かれる発言や、調べもの用の補助の AI にも、届くようにするためである。

### 2.4 視点・日時・時制（V1〜V4）

- **V1**　チャットの場面の文脈に、場面に設定した視点の人物の名前を、「この場面の視点」として足す。設定が無ければ、何も書かない。
- **V2**　視点の人物の Codex の項目が、今の場面の時点で hidden なら、渡さない。項目が Codex に無いときも、渡さない。
- **V3**　場面ごとの時制の設定欄は、今回は足さない。先に、作中の日時（M3・T4）と位置の区別を入れ、場面ごとの時制がなお要るかを見る。要ると分かれば、保存する値が増えるので、別の起案で確認する。作品全体の時制と視点の設定は、今までどおり渡す。
- **V4**　現実の今日の日付は、渡さない。

### 2.5 MCP（X1〜X2）

- **X1**　場面を指定して年表の状況を読む道具は、画面側と同じ規則にする（CED/1 の K2）。
- **X2**　一覧・詳細・人物の年表への位置の印は、この案に含めない（決定 7）。確度は、CED/1 で渡す。

## 3. 残る制限と、脅威モデル（draft）

残る制限
- MCP の一覧は、位置の印なしで渡る（X2）。MCP の向こうの AI には、前後の区別が無い。
- 位置の印は、道具を呼んだ時点で開いている場面に対するものである。発言の途中で場面を切り替えると、基準が変わる。
- 確度が「不明」の出来事の印は、仮の日時で決まる。承認して入れた出来事は、抽出のときの推定が入るまで、根拠の場面の日付か、仮の日時を持つ（CED/1 の G2〜G5）。印が外れることがある。確度を添えるのは、そのためである。
- 回想の場面を書いているときの現在地は、場面に作中日付が無ければ、手前の場面から借りる。回想の時点とは、合わないことがある。
- 位置の印は、AI への手がかりである。AI が印を無視して、先の出来事を書くことは、防げない。

変えるものは 3 つある。自動のまとめの選び方と「作中の現在地」は、CED/1 の脅威モデル（Z6）に置く。

| L1 道具の返り値に、位置の印・確度・今の場面の情報を足す。道具の説明に、読み方を足す。自動のまとめの見出しと文を直す（W・M1〜M4・T） | 作者、画面側の年表の読み取り | AI の出力 | 印が誤って「これまで」になり、AI が先の出来事を、起きたこととして書く。作者が印を付けた出来事が、印の処理で見えるようになる。返り値と説明の形が変わり、道具の作り直しの lane の、固定した期待値と食い違う | 秘密の印の判定を先に掛け、その後に位置の印を付ける。出来事は除かない。確度を添える。返り値と説明の期待値は、人が見て作り直し、PR の本文で示す | 外部の AI の提供者に渡る内容に、位置の印と、今の場面の題・作中の日時が加わる。今も、出来事の詳細は、結び付いた場面の題を返している【報告】。送信先は増えない。AI への指示の変更なので、品質の検査を通す |

| L3 自動のまとめに「これからの出来事」の欄を足す（M5）。**測定の後に、入れるかを決める** | 作者 | AI の出力 | AI が、先の出来事を、起きたこととして書く。先の展開が、作者の望まない所で文章に出る。作者が印を付けた出来事が欄に入る | 秘密の印のある出来事と、確度が「不明」の出来事は入れない。指示の文を添える。件数の上限を持つ | 外部の AI の提供者に、毎回、印の無い先の出来事が渡る。手書きの出来事も含む。測定の結果を見せ、別に確認する |

範囲外：新しい送信先（無い）。保存の範囲（変えない）。AI が返す文章の点検。MCP の一覧への位置の印（X2）。

## 4. 順番と、測定

### 4.1 PR の列

1 は、CED/1 を待たずに出せる。2 以降は、CED/1 の §5 の 5（比べ方の切り替え）の後に出す。道具の作り直しの lane との前後は、CED/1 の §5 の冒頭と同じである。

1. **視点の人物**（V1・V2）。ほかと独立である。
2. **自動のまとめの見出しと文と「同じ頃の出来事」の欄、道具の返り値と説明**（W・M1〜M4・T・X1）。年表の設計書と、AI に渡す文脈の説明書の、該当の部分を直す。今の道具（`chronicleReadTools.ts` と検索の道具）と、道具の説明の正本に入れる。固定した期待値を作り直し、差分を PR の本文に載せる。
3. **「これからの出来事」の欄**（M5）。測定と、ユーザーの決定の後である。

AI への指示を変える PR は、品質の検査の手順（`grimodex-author`、`grimodex-impact-gate`）を通す。

### 4.2 「これから」の欄の測定

決定 6 による。比べるのは、欄がある場合と、無い場合である。数えるのは、AI の返す文章に、先の展開がどれだけ出るかである。題材、場面の数、条件の細部（指示の文の有無を分けるか）、数え方、費用の見込みは、始める前に、別の文書でユーザーに見せる。凍結済みの評価の題材は使わない。生成は、製品の送信をそのまま使う必要が無い限り、補助の AI で行う。
